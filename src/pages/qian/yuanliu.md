## 六十甲子

古人用十个天干（甲乙丙丁戊己庚辛壬癸）和十二个地支（子丑寅卯辰巳午未申酉戌亥）依序相配，配到第六十个，回到“甲子”，叫做一个甲子。年、月、日、时都可以这样来记，所以“六十甲子”是中国传统纪时法的底盘。

闽台等地的庙宇里，常见一种“六十甲子签”：六十支签，依次对应甲子、乙丑，一直到癸亥。签诗写在签纸上，求签的人拿着签号去领。

| 内容 | 出处 |
| --- | --- |
| 干支相配、六十一循环 | 古籍。干支纪法自古沿用至今 |
| 庙里常用六十支甲子签 | 民俗，各庙的签诗各不相同 |
| 本作共六十一支：六十甲子，外加一支“签头” | **本作原创**的设计 |
| 每支签的名字，取自成语典故 | **本作原创**的选择 |
| 每支签的七言四句签诗、白话解说、三个方面的建议 | **本作原创**，是作者与 AI Agent 一起写的，不是任何一座庙的签诗 |

## 纳音五行

“纳音”是给六十甲子再分一层类：每两位相邻的干支合用一个名字，例如甲子、乙丑同称“海中金”，丙寅、丁卯同称“炉中火”，一共三十种。它的末字是金、木、水、火、土之一，称为纳音五行。

这套说法见于隋代萧吉的《五行大义》等书，后世的命理书一直沿用。

本作怎么用它：

- 每支签的五行，取它纳音的末字，所以金木水火土正好各十二支。（**本作的用法**）
- 地支也配了五行（例如子属水）。你来问的那一刻，设备时钟推出时辰，同属那一行的签被抽中的机会加倍。（**本作原创**的设定，传统里没有这条规矩）

## 掷筊的规矩

筊杯是一对月牙形的小片，一面平、一面凸。向神明请示时，把它掷在地上，看朝向：

- **圣杯**：一平一凸，神明应允。
- **笑杯**：两面都平，神明没说清，再掷一次。
- **阴杯**：两面都凸，神明不同意。

求到签之后，还要用掷筊确认这支签是不是神明给你的。不少庙宇要求连得三次圣杯，这支签才算数。以上是闽台民间的通行做法；各庙的细节不完全一样，本作取的是其中最常见的一种。

本作在这上面加的东西：

- 三杯都由你亲手掷。（**本作的设计**，意在让“被神明回答”变成一个你自己做的动作）
- 得了阴杯之后，除了依规矩重求一支，还可以选“我偏要这支”。（**本作原创**，传统里阴杯就是要重求）
- 重求、偏要、犹豫了多久，都会被大师记下来，织进结尾的命盘。（**本作原创**）

## 四种结局

结局不看签的好坏，只看你怎么对待被给出的答案。

| 结局 | 怎么触发 |
| --- | --- |
| 遵命 | 三个圣杯，受签 |
| 逆命 | 阴杯之后，选“我偏要这支” |
| 迷障 | 一直重求，求到第三支签 |
| 破执 | 按下左下角的“存疑”，不再相信这场推演 |

四种结局是**本作原创**的叙事设计，与传统签法无关。

## 注疏

仪式里带点线的词，桌面上会在右侧的“注”栏里出一条注，手机上点开是浮注。注讲传统：这个词是什么，从哪里来。眉批是大师在说你，注是在说传统，两者不混。

注和这一页的全部文字，都是作者与 AI Agent 一起整理的初稿。其中涉及古籍与民俗的说法，若与你所知的庙里的规矩不同，以你所知的为准。
