# 设计规范：古书 × 宣纸朱批 × 摇动控制

> 所有美术改动以本文为约束，改完逐项过 §9 的检查清单。
> 早先的方向"立轴 × 绀纸金泥"（深蓝纸、泥金字）已弃用：泥金在手机上难读，而朱批的"审阅"关系与作品立意直接对应。
> 2026-10-24 起，整个作品改成**一册摊开的古书**，每走一步翻一页；同日再改：**书就是大师，仪式在书外**（§19）——大师的话是书页空白处渐渐洇出的字迹，摇签、掷筊、起卦、灼这些仪式用案上的实物完成，书只记下结果；早先的朱丝栏、双线版框、右侧注栏、天头眉批栏、墨晕换屏都已拿掉。

## 一句话

整个作品是一册**古书**：摊开在案的里侧，宣纸为底，墨写正文；**书就是大师**。他不再有固定的眉批栏，话是**字迹**：从当前书页的空白处一笔一笔洇出来，停一会儿，再渗进纸里、淡去；朱笔只用来圈点（句尾的"〇"、关键数字、警示句的着重点），像皇帝批奏折时的圈点。**仪式在书外**：木牌、签筒、筊杯、龟壳铜钱、龟甲炭火摆在书前的桌面上，玩家用它们摇、掷、灼；结果出来时，书页上浮现出来——签文、每一杯、每一爻、兆和刻辞，书页只记录结果，所以每一页都是"写下来的"，可以回看。问事与命辞是书上唯一需要玩家动手输入的地方：字被纸吸进去，书再用字迹回一句。书自己也有动作（犹豫时轻颤、重来时合拢再开、存疑时撕开、结局时落印），克制，不干扰阅读。器物用**水墨写意**来画，但按**真实物理**来动。版式见 §19。

## 1. 为什么是书写的话与圈点

旁批是作品核心：大师一边看你求签，一边给你下判断。话是写在书页上的字迹——上位者审阅、批示的位置；朱笔的圈点落在它身上——被观察、被评判的关系直接画进了视觉里。

（早先批语整句用朱色，后改为淡墨：满篇的红字抢了正文，也让"朱色"不再稀有。现在朱色只落在最该被看见的点上。2026-10-24 起批语不再有固定的天头栏，而是写在书页的空白处，见 §4 与 §19。）

## 2. 纸面

| 元素 | 做法 |
|---|---|
| 宣纸 | 暖白 `#efe6d0`，叠纤维纹与低频的深浅斑驳；内容上方再盖一层极淡的纸纹，墨字与朱印也带纤维，像印在纸上。**不用 `mix-blend-mode` 混合整层内容**（Chrome 下出现色带，老旧内置浏览器风险更大）。噪声图案的频率 × 尺寸须为整数，平铺才无缝 |
| 书 | 一册摊开的线装书（§19）：左右两页，中缝是书脊的阴影，页边叠着几层纸边显出厚度，书落在案上有一团软影。**不画朱丝栏、不画双线版框、不画方格**；版心只留极淡的鱼尾与页码 |
| 书的话 | 没有固定的栏：大师的话写在**当前书页的空白处**（见 §4） |
| 天头栏与页脚 | 书的上方是天头栏（卷名、回目录、源流与关于、通灵开关、昼夜印、声），下方是页脚（这一步的说明、步骤、按钮）；它们是坐在案上的两条深色的栏，字用纸白（§19） |
| 案 | 桌面上书的外侧是"案"（`.an`），案上铺着深墨色的字盘（`#an-board`，见 §13、§18）；**书摊在案的里侧，器物摆在书前的桌面上（`.desk`，§19）**；手机上书在上、器物在下，天头栏与页脚固定在上下 |
| 枯笔墨痕 | 每屏至多一笔大墨痕做构图骨架（SVG 路径 + 位移与条纹滤镜模拟飞白），标题可反白压在墨上 |
| 墨点 | 少量溅墨点缀，不超过 5 处 |

| 纸（`--paper`，旧名 `--gan`） | `#efe6d0` | `#d3c297`（灯下的暖黄纸，稍暗） | 书页的底 |

浅色下不用金色，不用满屏红金。

## 4. 字

字体族名集中在 `src/core/styles/base.css` 的三个变量里，换字体只改这一处（来源见 `tools/subset-fonts.py` 的 `DISPLAY`）。

| 用途 | 变量 | 字体 |
|---|---|---|
| 卷名、标题、签名、签诗、卦名、结局名、印文 | `--f-display` | **汇文明朝体** Huiwen-mincho（日式明朝体的古籍味）。许可待确认，见 CLAUDE.md |
| 书的话（旁批）、注（纸条上的小字）、账本旁注、通灵的"实话" | `--f-kai` | **霞鹜文楷** LXGW WenKai Regular（OFL 1.1，v1.530）。书的话用**淡墨（墨 80%）**，手机 17px、桌面 19px；朱色只给句尾"〇"、关键数字（自动识别文中的数字与百分号）、警示句的着重点。**不用草书**：草书在手机上认不清 |
| 正文、按钮、表单、账本 | `--f-text` | 思源宋体 Noto Serif SC（400，小标题与注的术语名用 600） |

汇文明朝体没有的字（如卦名里的"夬""姤"）回落到思源宋体；"筊"在两款字体里都有。字体都是按站内用字裁出的子集，改了任何中文文案后要重跑 `python tools/subset-fonts.py`；霞鹜文楷另有一个按 GB2312 一级字库裁的 `unicode-range` 文件，给通灵实时生成的字用。

**按钮、表单、导航、账本不用书法字体**，保证可读。手机端正文不小于 16px，说明文字不小于 14px。

书的话（`src/core/gloss.js`；文件名与 `ctx.gloss()` 沿用旧名）：大师的话**不再有固定的栏**，写在当前书页的**空白处**。队列、去重与节奏的规则全部保留，只换了呈现与位置：

- **文字先整句排好版，再逐字洇开**：每个字一开始就在 DOM 里，只是被动画延迟压着没出现，所以写字的过程中版面纹丝不动。
- **折行落在句读上**：按标点切成语段，每段是不可拆的一块，放不下时整段移到下一行，不在词或"3.9 秒"中间断开；不用省略号截断。
- **找空白**：先把这句话在几种宽度（330 / 270 / 220px）下排一排量出高度，再扫两页（先右页、后左页）：用 `Range` 取出页上每一段文字的行框，加上图、画布、输入框、签卡、命盘等的包围盒，各向外留 16px，再避开还没淡去的别的字迹；在剩下的空白里选偏页心偏上、略带随机的一处，字迹略歪（±0.9°）。**不遮正文**。找不到放得下的空白，就写在页边（右页上缘），字带一圈纸色的柔光，字号小一号。刚进卷、刚换屏、页还没排好时先等一等（`pageReady`），免得写在后来出现的内容底下。
- **说完停一会儿，再渗进纸里**：写完停 1.5 秒加每字 85ms（至多 3.6 秒；后面排着队时只停 0.5 秒），然后 `opacity` 与 `filter: blur` 一起在 2.6 秒里慢慢退去（`is-sink`）；被顶替时 0.3 秒快速淡出。
- **同一类话只留最新一条**（`key`；如连点"功名、尘缘"时，新的顶替旧的，不排队）；后面排着队时写得更快、停得更短。
- 句尾圈"〇"（朱）在版面里先占好位置（不显示），写完才显出来，免得最后一刻把末段挤到下一行；关键数字用朱（`marks.js`）；警示句的着重点用朱。
- **翻页时暂缓**：翻页的这一秒里先不写；正在写、还没写完的那一条，翻过去之后在新的一页上重写（`gloss.hold`）。**回看写下的页时大师不开口**（`setLive(false)`），回到最新一页再接着写。
- **减少动效**：不逐字洇开，整句淡入、淡出（`.is-plain`）。

## 5. 器物：写意的画，真实的动

- 签筒、竹签画成**水墨**：淡墨晕染的筒身、粗细不匀的墨线、竹签是一笔笔墨痕；筒身只盖一方朱印。
- **印**：外缘不规则、内框线断续、朱面剥蚀（越靠边越密、中心近乎完整），像石头刻的、蘸印泥盖的。网页上的 `.seal` 用一道静态的 SVG 位移滤镜起毛边（只在绘制时算一次）加纸色噪点蒙版；摇签筒上的印在转动的组里，不能用滤镜，改用静态的不规则路径加碎点；分享图里的印用 Canvas 按种子画出同样的做法。
- 筊杯保留红漆实物色，用墨线勾边，像工笔着色。
- 落地溅起的是**墨点**，不是金粉。
- 物理与输入见 §6。

## 6. 摇动控制

- 手机加速度计为主输入：倾斜决定器物倾角，晃动力度累积成"能量"；iOS 在第一次点击时请求权限。
- 回落：按住器物左右拖动；按住不动时器物自己轻摇；键盘按住空格。
- 器物本身就是控件，文字按钮只作回落与无障碍入口。
- 按能量出结果，不按计时。
- 每次碰撞同时有画面、声音、震动（安卓）。

物理参数：重力 2400 px/s²，倾角弹簧 k 90 / 阻尼 12，落地恢复系数 0.35，摩擦 0.8，固定步长 1/120 秒。一次摇签 2–4 秒；签落地到签诗出现不超过 1 秒。"减少动效"时跳过飞行与弹跳。

## 7. 避免

（部分借鉴 InkView 的设计原则，MIT：https://github.com/qybaihe/inkview ；未采用其 PNG 素材，因本项目不引入位图）

- 宫廷红金、仙侠游戏界面、影楼古风；
- 发黄做旧的脏纸、压在小字下的纹理；
- 给每个元素都描一圈边框——墨线用来分隔，不用来包框；
- 书法字体用在按钮、表单、账本上。

## 8. 墨与水：会动的纸（2026-09-30）

纸面静止时什么都不多画；只有指尖点按、换屏、落签这些时刻，才有墨或水出现，随后淡去。实现在 `src/core/ink.js`（一层盖在书上的画布，夹在内容与纸纹之间，所以墨与水也带着纸的纤维）。

| 时刻 | 效果 | 说明 |
|---|---|---|
| 签卷入口载入 | 墨痕被一笔"写"出来，标题随后在墨里洇出 | 墨痕是静态图 `public/img/title-ink.svg`（光栅化一次），"写"是平移一张预先带飞白毛边的蒙版，每帧不重算滤镜（手机上像素多，逐帧重算会卡） |
| 签卷入口静候 | 墨痕边缘每隔一两秒洇出一团极淡的墨晕，慢慢扩大、淡去；偶尔下缘鼓起一颗墨珠，坠下，落在纸上洇成一小团、荡开两圈水纹 | 只在签卷入口屏、页面可见时（卷首目录页是静态的，不放墨痕）；**不画线**（卷须像蜘蛛腿，拖出的流痕像蛛丝，都已去掉） |
| 任何点按 | 一小团柔边淡墨晕 + 两圈水纹 | 红色按钮与签筒上不落（按钮自己有按下的反馈，签筒上手指一直在动） |
| 换屏 | **翻一页**（§19）。早先的"从指尖洇开"已由翻页取代 | |
| 书的话 | 每个字由糊变实，写在书页的空白处，说完渗进纸里 | 见 §4 |
| 落签 | 签名像盖印一样落下（带回弹），落点洇开一团墨晕、起一圈水纹；签诗逐字洇开 | 摇签时落地的墨点落纸后会再洇开一圈 |
| 掷筊落地 | 两块筊落点各洇开一小团墨晕和水纹 | |
| 结局 | 印章在进入视野时盖下，洇开一团朱晕和一圈水纹；判词、"不过……"逐字洇开 | 用 IntersectionObserver，滚到才播 |
| 通灵等待 | 一滴墨落进纸里，化开，隔几秒再一滴，伴一声水滴 | 取代三个闪动的圆点 |
| 写下问题 | 玩家写在书页上的字，点"定"后被纸吸进去：糊一下、字距略松、再沉成一行淡墨（`.ask-written.is-soak`，1.5 秒） | 随后书用字迹回一句 |

约束：

- **质感取"水洇在宣纸上"**：边缘柔和的淡墨晕，加细而淡的水纹。**不画放射的细线（像蜘蛛腿），不画吊着的细线（像蛛丝）**——早先试过的墨晕卷须与流墨，就因为像蜘蛛而去掉了。

- 画布只在有动静时才跑 rAF，静止时零开销；运动中的东西不用 SVG 滤镜，靠柔边的径向渐变叠层。
- 朱色规则不变：只有印与朱批带朱，所以朱色的晕与纹只出现在按印、落印时；墨与水一律用墨色。
- "减少动效"下：画布层整体关闭（`createInk` 返回空实现），不翻页，通灵等待退回三个点，其余 CSS 动画被全局规则压成瞬间。
- 调试：页面加 `?debug` 后有 `window.__fx`，`__fx.advance(dt)` 可手动推进一帧（面板隐藏时 rAF 会暂停）。

## 9. 每屏完成前的检查

1. 底是宣纸（深色是磁青纸），**没有朱丝栏、版框与方格**；书有书脊的阴影与纸边的厚度；
2. 每屏至多一笔大墨痕；
3. 朱只用于印章、朱批圈点（〇、关键数字、着重点）、阴杯、最终判词与关键操作按钮；书的话、账本旁注、"实话"与注的正文是墨；
4. 字体分工对（§4）：标题、签名、签诗、卦名、结局名、印文用汇文明朝体；书的话、注、旁注、"实话"用霞鹜文楷；正文、按钮、表单、账本用思源宋体，对比度足够；
5. 器物是水墨画法，能摇、能按住、能用键盘；
6. **仪式在书外，结果写进书里**（§19）：器物摆在案上，书页只放结果；**说明与按钮都在页脚**（这一步的说明文字、主按钮朱印、次按钮、步骤进度）；源流、关于、通灵开关在天头栏，不留在书里；
7. 换屏是翻一页；**没有"上一页 / 下一页"按钮**，书本身可点、可拖页角、可用方向键；往回自由翻看（只读），往后最多到最新一页，再往后书抗拒弹回；**减少动效下不翻、不抗拒动画，直接切换**，流程仍能完成；
8. 内容放不下就分页（结局的几页，可自由翻），单页里不出现长滚动条（长文的源流与关于页例外）；注是点术语才贴的纸条，不出滚动条；
9. 桌面 1440×900、1366×768 与手机竖屏 375px 宽下都完整可见；
10. 新增的动效符合 §8：静止时不多画、朱色只给印与朱批圈点、减少动效下可跳过；
11. 字盘、透字、开卷符合 §13：只用 transform / opacity（开卷用 clip-path，一次性）、静止零开销、页面隐藏时暂停、字盘本身是墨色；
12. **两套主题各看一遍**（天头栏上的"昼/夜"印，或在系统里切换配色）：**书在深色下仍是纸色（暖黄）、字仍是墨**，对比度 AA；朱色规则；金色只出现在书外的装饰上；案与字盘沉进黑暗，书上方有灯的光晕；Canvas 与 SVG 画的东西是否跟着换色；分享图仍是浅色宣纸；**深色下没有绢帛飘带**，只有字盘；
13. 3D 场景符合 §18：页面不可见时不渲染、静止与悬停暂停时不逐帧画、dpr ≤ 1.5；手机宽度、`pointer: coarse`、减少动效、WebGL 不可用时退回 2D 字盘。

## 10. 命盘与分享图（2026-10-02）

## 12. 注与卷首目录（2026-10-22，2026-10-24 改成按需）

卷首目录（`/`）：这本书的目录页。左页是书名（竖排）与"目录"二字，右页是目录：竖排，自右向左，每卷一列：卷名（汇文明朝体）、全称、点线、页码，旁边一句简介；开了卷的盖一枚"入"字朱印，未开卷的墨色更淡、不可进入、标"未开卷"。点开了卷的卷名，**书里翻一页进入那一卷**（ClientRouter，不整页刷新，§19）。

## 13. 案上字盘、纸背透字、开卷与盖印（2026-10-22，2026-10-24 改）

### 案上字盘

书之外的"案"是一盘**反刻的阳文活字**（书与字盘用 `transition:persist` 常驻，换页、换卷都不重建 three.js 画布；字盘的用字按**首次载入的页面**定）：深墨底（`#2b2620` 到 `#14120f` 的径向渐变，盘边再收暗），每个字是一枚浮雕般的铅字，字身镜像，亮边在左上、暗边在右下，字色只比底亮一点点（低对比，不抢书页）。桌面上它从书的两侧与上下露出来；手机上书占满全宽，只在天头栏与页脚的半透底下隐约透出。

| 项 | 做法 |
|---|---|
| 实现 | `src/core/paper/board.js`：按案的尺寸把一盘字**一次性**画在离屏画布上（桌面格 38px，手机 22px；整盘镜像，行内次序也是自右向左；约 5% 的位置是空铅），上下两幅相同，再用 CSS `transform: translate3d` 循环滚动一个 `tileH`（约 9px/秒）。滚动时不重绘、不跑 rAF；窗口尺寸变化后（防抖 250ms）重画一次。画布最多 dpr 1.5，纹理总量压在约 9M 像素以内 |
| 字 | 一律用思源宋体（活字感），只取 BMP 里的汉字，扩展 B 区以后的字一律不用，免得没有字形时回落到系统字体、显示成方框。部首表里思源宋体没有字形的字已经事先剔出（`shuowen-bushou.js`） |
| 按卷取字 | 路径第一段是卷 id 时，取该卷模块的可选字段 `zipan`（字符串，或返回字符串的函数，可异步，见 `src/juan/index.js`）；没有 `zipan` 的卷、卷首目录页与静态页，用《说文解字》540 部首（`src/core/paper/shuowen-bushou.js`，公有领域）。各卷用什么：签＝六十一首签诗，卦＝《周易》经文，卜＝甲骨卜辞释文，字＝《说文》，历＝历书宜忌用语；目录＝《说文》部首 |
| 悬停与按住 | 鼠标悬停在字盘上，整盘暂停，移开恢复（`:hover`，仅 `hover: hover` 设备）；触屏按住暂停，松手恢复；页面隐藏时暂停（`visibilitychange`） |
| 点一个字 | 那里"拓"出一枚**小朱印**（朱色，阴文，字是拓回来的正字），随那枚铅字一起滚；同时洇开一团墨（`ink.js` 的 `wash`，在深底上用比底更黑的墨，水纹是一圈淡淡的亮痕）。朱印停 5 秒后淡去，最多留 8 枚。朱印另放一层、盖在墨晕之上，与字盘同一段动画，所以暂停与滚动始终同步 |
| 减少动效 | 字盘静止；点击仍落朱印，只是没有动画，也没有墨晕（`createInk` 返回空实现） |
| 约束 | 字盘本身是墨色，不用朱；只用 transform 与 opacity；静止时零开销（实测静止 3 秒内页面脚本的 rAF 调用为 0，墨晕散尽后也为 0）。书放在字盘案上，天头栏与页脚是盖在字盘上的两条半透的深色栏 |

### 纸背透字

右页里的**镜像大字**，像背面的字洇透过来。只在卷首目录页用（`BookFrame.astro` 的 `tou` 参数，一个字符串，取前三个字；图谱页以后接，传同一个参数即可；Codex 画在右页底下）。

- 不透明度 4–6%，字号 120–380px，各自按 140 / 170 / 200 秒来回漂 26–34px（`transform`，`alternate`），压在正文之下；手机上只留两个字。
- 字用思源宋体，墨色。页面隐藏时暂停，减少动效下静止。
- 它不是"每屏至多一笔大墨痕"的那一笔：墨痕是构图骨架，透字是纸本身的底色，更淡、更慢，不参与构图。

### 卷首开卷

进入目录页的**本次会话第一次**（`sessionStorage` 的 `stj-kaijuan`；书是常驻的，只有首次载入才播），书像卷轴一样展开：整册书用 `clip-path: inset(-30px 50% -30px 50%)` 揭开到全幅，两根轴（墨褐木轴，不用金）从中缝滚到两边，最后淡去。1.15 秒，缓出缓入。决定放在 Codex 挂上的那一刻（`onMount`，换页后不再播）：加上 `html.kaijuan`，1.5 秒后拿掉。书是客户端岛，首帧之前页面上本来就没有书，不会先闪出整页。减少动效下跳过，也不记标记以外的任何状态。

### 印章按下

所有朱印按钮（`Seal.svelte`）共用：

1. **按下**（`:active`）：印往下压，`translateY(2px) scale(.9)`，略暗，60ms。
2. **松手**（`click`，键盘激活同样）：`.is-print` 播 0.42 秒的一震（回弹到 1.05，再左右各偏 1px，落定），同时印边晕开一圈朱色（`box-shadow`，最远 `--s × 0.13`，淡去）。
3. 多数印按下就换屏、页脚里的按钮随屏换掉，一震还没演完：这时在原处留一枚**影印**（克隆的印，不接事件，挂在书或页脚上）把这一震演完再移除。
4. 毛边滤镜 `#seal-rough` 的区域放宽到 ±14%，印迹那一圈才不会被截掉。
5. 减少动效下全部跳过。

## 14. 卦卷的器物与卦画（2026-10-22）

- **龟壳与铜钱**（`src/juan/gua/shell.js`）：与签筒同一套做法（§5、§6）。龟壳是淡墨晕染的壳身，壳上几笔盾片的接缝，一方朱印；铜钱用旧铜的低饱和色（灰褐，不用金色），墨线勾边，字面是“天机通宝”四字，背面光素，只有星与月。运动中的器物不用 SVG 滤镜。
- **真实的动**：重力 2400 px/s²，落地恢复系数 0.35，固定步长 1/120 秒；钱从壳口飞出，飞行时转过整数个半圈，落地后在原地摇摆衰减，像一枚旋转的硬币慢慢停下，所以看到的朝向与记下的一致。接口与签筒相同，沿用公共的摇动控制（拖动、按住、晃手机、空格或回车）。
- **卦画**（`Hexagram.svelte`）：一爻一笔墨，沿路径一笔写成，不用滤镜；阳爻整条，阴爻中间断开；变爻旁点一圈朱（老阳〇、老阴×），属朱批圈点。
- **命盘的织法**：一爻一束丝；少阳平直，少阴在中间分开，老阳胀成一个圈，老阴在中间交叉；变爻的中段带一点朱。

## 16. 统计与隐私

作品本身讲的是"被算法旁观"，所以统计必须比作品里的大师老实：收什么、不收什么，都要写在玩家看得见的地方（账本页、关于页），并且与代码一致。

- **上报**：每局结束一条，只有卷、领域、结局（遵逆破迷）、本局结果标识（签号、卦序或兆象）、用时分档、是否写了问题、问题的类别（语气、主题）、昼夜主题，日期由服务端按天填。字段与枚举在 `src/core/stat-schema.js`，服务端一律白名单校验。
- **不收**：问题原文、IP、UA 原文、指纹、cookie、跨局的设备编号。同一个人的两局无法连起来。本地账本与上报的数据没有关联，也不会被上报。
- **IP 的用法**：只在服务器内存里哈希，作为每天的次数计数键写进 `hits`（单 IP 60 局、全站 5000 局，超限静默丢弃），隔天清理；不写进 `rounds`。
- **问题归类在浏览器里做**（`src/core/question-class.js`）：语气沿用观人术的犹豫、困惑、期待；主题是工作、学业考试、感情、家人、健康、钱财、搬迁出行、其他。词表是本作自己的设定，只是关键词匹配，会判错，不得当作语义理解来写。
- **对玩家说的话**：结局坦白里大师用第一人称说一句聚合数字（"今天来问功名的，有 35%"），数字点朱，复用 `marks.js`。只用当天或近 7 天；不足 20 局不说数字，改说一句不带数字的话；读不到聚合（离线、本地预览）就什么也不说。模板集中在 `src/core/peer-lines.js`。
- **隐私说明**：账本页说明"细节只在本地，另有一条匿名统计"并列出字段；关于页写全字段与限流用 IP 哈希的事，并说明通灵模式是例外（问题会发给 AI）。改上报字段时，这两处和本节一起改。
- **作者统计页** `/admin/`：令牌放 `Authorization: Bearer`，服务端与 `STATS_TOKEN` 常量时间比较，未设置一律拒绝；令牌只存 sessionStorage；页面 noindex（meta 与 `public/_headers`），不链接；图表用 SVG 自己画，不引图表库。页面自带样式，不走公共纸面。
- 带 `?debug` 的页面不上报。

## 17. 双主题：宣纸与乌金拓

| | 宣纸（浅色，默认之一） | 乌金拓（深色，书的夜间版） |
|---|---|---|
| 意象 | 宣纸、墨、朱批 | 夜里灯下的一册：**书仍是纸色**（稍暗，带一点灯下的暖黄），字仍是墨；案与字盘沉进黑暗，书上方有一盏灯 |
| 纸面 | 暖白宣纸，纤维与深浅斑驳 | `#d3c297`，纹理同浅色，只是底色换成 `--paper`（取消早先的磁青纸：看起来像负片，也与"书是纸做的"不一致） |
| 字色 | 墨 | 墨（`#1a1510`）；朱字更深（`#861b16`）；泥金只在书外的装饰上；正文对纸约 10:1（AA） |

| 案与字盘 | 深色的案，暖光 | 字盘整体压暗（`filter: brightness(.62) saturate(.55)`），再叠 `.an::after` 的两层渐变：一团暖光落在书与近处的桌面上（`--lamp-rgb`、`--lamp-a`），四周收进黑暗（`--dim`） |

- **机制**：`<html data-theme="light|dark">`。`Paper.astro` 的 `<head>` 里有一段内联脚本，**在首帧之前**设好它：先读 `localStorage['stj-theme']`，没有就跟随 `prefers-color-scheme`，读写都包 try/catch。之后系统配色变了，若玩家没手动选过，会跟着变。统计等代码读这个属性。
- **开关**：天头栏右侧，与"声"并列的一枚小朱印（印章式），写当前的主题——"昼"或"夜"，点一下换成另一个。`aria-label` 写明点了会换成什么。逻辑在 `src/core/theme.js`（`setTheme`、`onTheme`、`inkRgb`）。
- **颜色全走变量**（§3）。SVG 里的器物（签筒、龟壳）用 `fill="var(--obj-ink)"` 这类写法。**案上的器物坐在深色的桌面上，不论昼夜都用"夜里"那一套器物配色**（`.desk-items` 里局部重定义 `--obj-*` 与 `--ink` 一组变量）。书页的纸边层次（`--edge-a/-b/-line`）与向书脊渐暗的程度（`--gutter`）也是变量。
- **天头栏与页脚**坐在深色的案上，两套主题里字都是纸白（在 `.topbar, .botbar` 里重定义 `--ink` 一组变量）。
- **深色下只有字盘，没有别的飘动的东西**：早先深色下的"写经绢帛"飘带已删掉（浅色本来就没有，两边一致）。
- **Canvas 跟着换**：2D 字盘（`board.js`，换主题时重画）、3D 字盘（board3d）。**书页上的 Canvas（墨与水、命盘）昼夜都按纸色来画**（书是纸色），所以 `inkRgb()` 与 `weave` 不再随主题变。卦画是 SVG 变量；签卡是 CSS。龟甲是骨色的实物，两套主题下保持不变。
- **主题与 ClientRouter**：ClientRouter 换页时会把 `<html>` 的属性换成新页面的，`data-theme` 会丢。`Paper.astro` 的内联脚本在 `astro:before-swap` 里把当前的 `data-theme` 补到新文档上（也补 `theme-color`），并把动态加载的样式表带过去。
- **分享图保持浅色宣纸**：它是要带走的一张纸。`weave` 指定 `width`（离屏重织）时一律用浅色。
- **厚度**（CSS，克制，文字始终正面朝向）：签卡是有纸边与纸影的一张纸，悬停时随鼠标透视倾斜 ≤ 4°（`core/tilt.js`，仅鼠标，减少动效下不做）；朱印按钮有"印身"（下缘一道深朱）与软影，按下时下沉 3px、印身压平，松手的一震不变；小木牌（回目录、声）有木纹、亮边、暗边与下缘一线厚度。签筒、龟壳、龟甲只补光影，不改交互和物理。

## 18. 3D 场景层

three.js 只用于场景层（现在只有案上的字盘），文字、按钮、印章仍是 DOM。three 是 npm 依赖，**只在真正要用时动态 `import()`**（`board.js` 里），包是独立的一块，不进首屏。

### 3D 铅字字盘（取代 2D 字盘）

- `src/core/scene/board3d.js`：**一个 InstancedMesh**（一份盒子几何，几千个实例），每个字是一块有厚度的金属活字。字形图集（`atlas.js`）在运行时用 Canvas 画出反字，R 通道即高度；字面的凸起在着色器里对高度图取差分得到法线，边缘倒角在着色器里弯折法线，顶面受光、倒角出高光。不为每个字单独建几何体，不用位图素材。
- 字来自每卷的 `zipan`（同 §13）；约 5% 空铅；深色下约 4.5% 的字泛泥金。
- **交互**：鼠标移过，附近 3.4 格内的活字按距离抬起（每块略有差别，参考木盒里被抬高的活字）；点一下，那一块按下去，原地"拓"出朱印（阴文正字，在着色器里把图集沿 x 翻回来），并洇开一团墨晕（`ink.js`，画在其上的 2D 画布）；朱印停 5 秒后淡去，最多 8 枚；朱印、抬起量跟着那块活字一起滚。
- **滚动**：整盘约 0.24 格/秒向上滚（与 2D 约 9px/s 相当）；悬停（或按住）暂停；整盘只上移一格时才重写数据。
- 浅色：旧木盒里的铅字（灰褐金属，暖光）；深色：墨底，铅字泛冷光，偶见泥金。

### 性能约束

- 页面不可见（`visibilitychange`）时停止渲染，并取消计时器。
- 渲染节奏：有抬起、按下动画时跟随 rAF（落定后立刻停）；只有漂移（滚动）时约 18 帧/秒（`setTimeout` 50ms 再 rAF）；只剩朱印淡出时约 30 帧；**悬停暂停且没有动画时一帧不画**。
- dpr 上限 1.5。图集最多 1024 字（1536² 画布）。尺寸变化后只在需要更多格子时重建网格。
- 只重写动过的块的实例属性；整盘上移一格时才整体重写。
- 调试：`?debug` 后有 `window.__scene`（`stats()`、`step(dt)`、`hover(x,y)`、`click(x,y)`）。

### 退回 2D

以下任何一条成立，一律用 `board.js` 里的 2D 字盘（§13，功能等价；深色下按新配色画）：

1. 手机宽度（视口 < 960px）；
2. `pointer: coarse`；
3. `prefers-reduced-motion`；
4. WebGL 不可用，或three.js 加载、初始化失败、上下文丢失。

条件在运行中变化（窗口跨过 960px、系统设置变了）时会自动换过去（防抖 200ms）。`?scene=2d` 可强制 2D。

## 19. 书是大师，仪式在书外（2026-10-24）

### 一册常驻的书（路由）

整个站点只有**一册书**：`src/core/Codex.svelte` 是一个常驻的 Svelte 岛，画出天头栏、两页、案上的器物与页脚；字盘（`#an-board`）也常驻。`Paper.astro` 用 Astro 的 `ClientRouter`（`astro:transitions`）接管换页，书与字盘都加 `transition:persist`（名字 `codex`、`board`），换页时 DOM 与状态原样保留，**three.js 的画布与 WebGL 上下文不重建**（验证：换页前后 `canvas` 元素、`window.__scene`、`gl.isContextLost()` 都没变，渲染帧数持续增加，`performance.getEntriesByType('navigation')` 始终只有一条）。从目录点一个卷名，是**在书里翻一页**进入那一卷，不整页刷新；回目录、浏览器的前进与后退、直接输入网址都正常。

- **页面只交一个 `<template id="stj-page">`**（`core/PageData.astro`）：`data-kind` 是 `toc`（目录）、`doc`（关于、讲解、404）或 `juan`（某一卷，带 `data-juan`），四个 `data-part` 放左页、右页、页脚说明、页脚右侧的链接或按钮。用 `<template>` 装，内容不进文档树：不重复 id，读屏软件也不读两遍。Codex 在每次 `astro:page-load` 时读它：同一页只更新内容；换了页就 `turn()` 翻一页（回目录向前翻，其余向后翻），并 `resetBook()` 换一册新的。`BookFrame.astro` 仍是静态页的入口（目录、关于、讲解、404 的写法几乎不变）。
- **岛的状态不依赖会变的 props**：Codex 没有 props，页面信息从 `template` 读；常驻的卷由 `session.svelte.js`（`$state.raw` 的 getter/setter）暴露给页脚（存疑印、目录键）。`transition:persist` 默认保留岛的旧 props，本来就用不上 `transition:persist-props`。
- **踩过的坑**：① `<html>` 的属性会被新页面的换掉，`data-theme` 丢了——`Paper.astro` 的内联脚本在 `astro:before-swap` 里把它（与 `theme-color`）补到新文档上，同时把"新文档里没有的样式表"也带过去；② 动态加载的样式表（Vite 给动态 `import()` 的块注入的 CSS、Svelte 组件的 `<style>`）会在换页时被当作旧页面的东西清掉——所以各卷（`src/juan/modules.js`）改成**静态引入**，各卷的 `.css` 由 `Paper.astro` 静态引入，每个页面的样式表一致；③ 各卷的样式原来是各自单独加载的，现在同时在场，撞名的类要查（龟壳的 `.shell` 与页面外壳撞了，龟壳改名 `.kegui`；`.only-narrow` 加了 `!important`，免得被某一卷的 `display: flex` 盖掉）；④ 字盘的用字只在首次载入时按页面取，换卷不重建（重建就要新开一个 three.js 上下文）；⑤ 首屏要把整个 Codex（含三卷的代码与签簿、卦簿）下载下来：Codex 约 348KB（gzip 149KB），样式表 89KB（gzip 23KB），three.js 另一块 538KB（gzip 136KB）按需加载；⑥ ClientRouter 在开发服务器上的样式顺序与生产构建不同（`.screen-about` 的 `text-align` 在开发时被 `.screen` 盖掉），以生产构建（`npm run build && npm run preview`）为准。

### 翻页：写下的页与自由翻看

- **每一屏是一个对页**：左页是大师的页（这一步的名字、副题，以及屏要多放的说明——掷筊的规矩与图例、起卦的爻名、结局的解读与账本），右页是结果。手机只有一页，左页的内容用 `.only-narrow` 在右页里再排一份。
- **写下的页**（`book/book.svelte.js` 的 `hist`）：一屏写完、翻到下一屏时，旧的两页被封存成一份**快照**（克隆 DOM、补回画布与输入框的值、去掉 id、加 `is-snap` 关掉里面的动画）。最新的一屏是活的；往回翻到的都是快照，**只读**。等待中的空页（摇签时的"签还在筒里"）用 `<Spread record={false}>` 声明，不封存。重求、重起、再灼前的页**留在书里**（书合拢再打开，不清空）；回卷首、再来一局才换一册新书。
- **往回自由翻看**：点左页、把左页的页角往右拖、按左方向键。往后：回看中可一路翻到最新的一页；**在最新的一页再往后**——点、拖、按方向键——书会**抗拒**：右页的纸被拎起一点（15% 的转角，手机 22%），露出还没写的空白，再带点回弹地落回去，同时大师说一句（`Codex.svelte` 的 `RESIST`，5 秒内不重复）。**结局的几页是一起写好的，可自由前后翻**（`Spread` 的 `pager`：`{ i, n, to(i) }`）。
- **手势**（`book/gesture.js`）：在页上按下并横向拖超过 9px 就是拖页角：纸的自由边跟着指尖走（先用 `book/geo.js` 把指尖换算成页面坐标，再按 `acos((x + 偏移 - 书脊) / 页宽)` 换算成翻开的程度）；拖动时记下手的速度，**松手时过了中线、或者手是朝着翻过去的方向甩出去的**（`p + v × 0.16 > 0.5`），就翻过去，否则弹回；纵向为主的拖动留给页内滚动；点一下（没拖）翻一页；页里的按钮、输入框、链接、术语、对话框不触发翻页；鼠标按下时 `preventDefault`，拖动不会变成选字；触屏用 `touch-action: pan-y`。方向键左右同样翻页（输入框里不响应）。
- **怎么翻**（`book/flip.js`）：翻动的这一张纸（`.leaf`）正面是旧右页（回翻时是新右页）、背面是新左页（回翻时是旧左页），旧左页的快照暂时盖住新左页，所以底下的新页是真的。纸沿横向切成 **10 条**窄纸（手机 8 条），一条套着一条，每条相对上一条再弯一点，越靠纸边弯得越多；弯曲 = 随翻开程度的静态卷曲（`sin 2πe`，翻起时纸边领先、落下时落后）+ 动起来时纸边落在后面的动态卷曲（与速度成正比，一阶滤波）。CSS 3D（`perspective: 4200px`，`preserve-3d`）。**每帧只直接写各条的 `transform` 和暗部、亮部的 `opacity`，不用 CSS 变量**（见“性能预算”）。背面略透（`opacity: .92`），**正面不隐藏背面**，所以从背面能看到正面文字的反影；翻起的纸在底下那一页上投出影（`.lf-cast`，宽度随纸边位置、浓淡随翻起程度，各条的明暗随各自的角度）；纸两面也带同样的弧面光与纤维（与 `.pg` 共用样式）。背面的内容第一帧不造，之后每帧补两条（纸刚翻起时背面还朝着里面）。
- **怎么动**（`flip.js` 的 `springTo`）：弹簧，`p` 是“翻过去的程度”。点击翻页 `playLeaf`：从静止出发，ω = 7.4、ζ = 0.72，约 1 秒落定，落下时碰一下回弹（反弹系数 0.28）；松手后 `release`：带着手的速度，ω = 11、ζ = 0.62；抗拒（`bounce`）：被拎起一点（初速度），ω = 21、ζ = 0.3，欠阻尼，落回去时碰一下再抖两下。点击、拖动、抗拒是同一套。手机（单页）是一张纸绕左缘转开约 104°。`window.__flipSlow` 把弹簧放慢，便于截图。
- **书不会变形，所以不用再等布局停下**：案升起时只是器物升起，书的大小不变。`prepare` 里留着 `settle`（页的布局尺寸变了才等，最多 1.2 秒），作为兜底；页的尺寸一律用 `offsetWidth / offsetHeight`（布局尺寸），不用 `getBoundingClientRect`（见“书的仿真”）。
- **翻页期间**：书的话暂缓（`gloss.hold`），浮注收起，**3D 字盘暂停渲染**（`book.svelte.js` 往 `document` 广播 `stj-flip`，`board3d.js` 收到就停帧，翻完 `request()` 接着画）；再次换屏时上一张纸直接落定；回看时大师不开口。
- **减少动效**：不翻、不抗拒、不合拢，直接切换；仍能完成流程。页面不可见时也不翻。
- **调试**：`?debug` 后有 `window.__book`（`flip`、`view`、`ctx`、`nav(dir)`、`bounce(dir)`）；设 `window.__flipSlow = 10` 可把翻页放慢十倍，便于截取翻到一半的样子。

| 犹豫（静止八秒，`ctx.watch`） | 书轻颤一下 | `.book.is-tremble`（整本书，含封面与纸边）：±1.6px、±0.2°，0.85 秒；关键帧里带上 `var(--tilt)`，不丢书的倾斜 |
| 重求签、重起卦、再灼、对贞灼 | 书合拢一下再打开 | 两页、封面、页边的厚度各自绕书脊转 82°（手机 70°）立起成窄窄一条（0.43 秒；合拢时看得见两侧纸边的厚度），投影同时收窄，合拢时才换内容，停 0.22 秒，再打开（0.52 秒）；`perspective(2600px)` 写在各自的 `transform` 里；回卷首、再来一局同样合拢再开，并换一册新书 |
| 按下存疑印 | 右页被撕开一道 | 右页的快照按一道锯齿线裁成两半（`clip-path`），向两边错开并微转（0.9 秒），停 0.7 秒，替代原来存疑印上的撕开效果 |

### 书的话的位置

见 §4。要点：话写在**当前书页的空白处**（`.voice` 图层盖在两页之上、翻动的纸之下，`pointer-events: none`），先找空白，找不到写在页边；`ctx.gloss(text, { alarm, key })` 的接口与队列规则不变。书的新台词（待审读）：抗拒翻页（`RESIST` 四句）、没写问题时的回应（"你什么也没写，我就凭这块木牌来猜"）、合拢重来（"我合上这一页，再翻开一页新的"）；回应问题的那句沿用"你写了 N 个字，我读出了犹豫"，撕页沿用"你打断了我 / 你不想被我算"。

### 手机（< 960px）

书在上（单页），器物区在下，主按钮固定在页脚；有器物才升起（`--desk-h: min(280px, 36dvh)`），结果页没有器物时书占满。选择：**上下叠放**而不是切换——器物与结果同时看得见，不必来回点；书仍是一本有厚度的书（单页）：深靛封面露出一圈、下沿一条纸边（最高 9px）、页面右缘与四角的光照；没有倾斜与场景缩放，书和器物按高度上下分配。代价是书页只有约 270px 高，所以手机上 `.screen` 的上下内边距收紧（不再为眉批栏留 68px），标题 32px，步骤进度只展开当前一步，源流与关于移到页脚。左页不显示。

### 翻页组件的选型：StPageFlip 原型（`page-flip`，MIT）

按要求先用 StPageFlip 的 HTML 模式做了原型（离线页，无头 Chrome 实测），重点测四件事：

| 测什么 | 结果 |
|---|---|
| 页里的按钮、输入框、Canvas | Canvas 的像素翻页前后不变（ID 唯一）；**输入框默认不能聚焦**（页的 `mousedown` 被吃掉，点输入框后 `activeElement` 为空、插入文字无效）；要给每个输入框、按钮补 `mousedown`/`touchstart` 的 `stopPropagation` 才行 |
| 手机竖屏（portrait）会不会克隆 DOM | **不会**：HTML 模式下 portrait 只是隐藏另一页，页里的元素唯一（画布与输入框的值不丢）；翻页方向也对 |
| 能不能锁住往后翻 | **没有 API**。只能在事件层（捕获阶段）自己拦、或翻了再 `flipPrev` 拉回来，后者会闪 |
| 能不能动态加页 | `updateFromHtml(items)` 可以，页数更新、输入框的值保留，但会重建整个页树 |

最后**退回自写的 `flip.js`**，补上点页与拖页角。理由：① 输入框默认失灵，每个交互元素都要打补丁；② 它要接管页元素的所有权（把页移进自己的容器、固定宽高比的 `stretch` 尺寸），而这里的页是 Svelte 管的活页，再加上案升起时书的高度会变，与它的固定比例冲突；③ 往后翻的锁要自己拦截事件，"抗拒并弹回"做不出来；④ 现有的翻页已经有分条弯曲、纸影、快照（翻页时底下是真的新页），补点页与拖页角只多了约 150 行。turn.js 许可不清，不用。

### 书的仿真（2026-10-24，R3）

**固定大小的场景，整体等比缩放。**桌面（≥ 960px）上，书与案是一块 1140×820 的场景（`book.css` 的 `.scene`）：书 1060×630（两页各 530×630，宽高比永远不变），案前留 262px 摆器物。窗口不够大，就整体等比缩小（`Codex.svelte` 里 `ResizeObserver` 量好比例写进 `--k`，不放大超过 1.12 倍）；**任何一屏都不单独压缩书的高度**。书里所有字号、间距因此不再随窗口高度变（原来的矮窗口媒体查询只留给手机）。1366×768 时整体约 0.78 倍，正文约 12px。

**书平放在案上：**
- `.book-wrap` 给 `perspective: 2000px`，`.book` 绕底边 `rotateX(11deg)`：远处略窄（约窄 5%）、近处略宽。翻页的 3D（`.leafbox` 自己的 `perspective`）在 `.book` 的平面里，先压平再倾斜，互不干扰。手机不倾斜（`--tilt: none`）。
- **封面**（`.cov-l/.cov-r`）：深靛布面（`--cover` / `--cover-edge`，深色主题略暗），比书页大一圈（左右各多 13px，上多 11px，下多 38px），横竖交织的细线做布纹（CSS 渐变，不用位图），下沿一道深色的板厚，书脊处向里凹。
- **纸边的厚度**（`.bk-l/.bk-r` 里的 `.eb` 下沿、`.es` 侧边）：层层叠叠的纸边（`--edge-a/b`），下沿靠书脊一端收窄（`border-radius` 的椭圆角），**左右厚度随翻到哪里变**：`Codex.svelte` 按 `progress`（对页序号 / 8；目录 0.1，说明页 0.5）算出 `thickL = 3 + 17p`、`thickR = 3 + 17(1 - p)`（px），写进元素的 `height / width / left / right`，`transition` 0.9 秒（不用 CSS 变量，免得整本书的子树跟着重算）。
- **落在案上的影**（`.bk-shadow`）：三层 `box-shadow`，贴地的一圈（0 2px 3px）又深又实，往外渐淡；书脊下沿多一团径向渐变。

**页面是弧面：**`.pg::before` 是盖在内容上的光——订口暗（`calc(var(--gutter) * 1.9)`）、向外分多级渐亮、中段最亮（极淡的暖白）、外沿微暗，再叠上下的晕边、四角泛黄的径向渐变；文字、签卡、器物图像一起受光，文字本身不变形。深色主题再加一盏灯照亮的一块（`--lamp-pg`）。纸纹是静态的（`.pg` 与翻动的纸共用同一份 SVG 纹理背景）。页角的圆角各不相同（`4px 1px 2px 7px`），纸不是一块规整的矩形。

**坐标换算（`book/geo.js`）：**书在缩放、倾斜过的场景里，`getBoundingClientRect` 量出的是屏幕上的外接矩形，不是页面里的 px。`.huaxin` 四个角各有一个零尺寸的探针（`.probe`），`bookMap(huaxin)` 读出它们的屏幕位置，解出透视变换，提供 `toLocal / toScreen / rect`。凡是要“屏幕 → 书里”的地方都走它：拖页角（`gesture.js`）、书的话找空白（`gloss.js`）、墨与水落点（`ctx.fxPoint`、点按落墨、`Title.svelte`）、印章的影印（`Seal.svelte`）；页的尺寸一律用 `offsetWidth / offsetHeight`（`book.svelte.js`、`motion.js` 的撕页、`ink.js` 的画布尺寸）。

### 性能预算

测量方法：Chrome 真实 GPU（Windows，D3D11，显示器 240Hz），`Tracing` + 页内 `requestAnimationFrame` 与 `PerformanceObserver`（`longtask`、`long-animation-frame`），1440×900；`Emulation.setCPUThrottlingRate(4)` 模拟 4 倍降速。同一套脚本、同一个流程（目录 → 进卷 → 择域 → 写问题 → 摇签 → 回翻 / 往后翻 / 拖页角 / 抗拒）在改前、改后各录一遍。

| 指标 | 预算 | 改后（1 倍 / 4 倍降速） |
|---|---|---|
| 主线程长任务（> 50ms） | 0 | 0 / 偶发（4 倍时翻页第一帧约 55–65ms） |
| 翻页、拖页角的帧率 | 60fps；4 倍降速 ≥ 30fps | 翻页期间主线程每帧约 1.2ms；> 17ms 的帧每次翻页 ≤ 3 帧；4 倍降速下平均仍有 210 帧/秒（显示器 240Hz），最长帧 ≈ 60ms 只出现在纸刚造出来的第一帧 |
| 翻页时样式重算 | — | 一次回翻 2.2 秒内 394ms → 60ms（改前把 `--rot` 等变量写在 `.leafbox` 上，每帧都让底下所有克隆出来的页重算样式） |

**不能做的写法：**
- **不要把每帧变化的值写成 CSS 变量，尤其写在有大子树的祖先上。**自定义属性默认继承，一变就让整棵子树（翻页时有二十份克隆的页）重算样式。直接写到要变的那个元素的 `transform` / `opacity` 上，并且值没变就不写（`flip.js` 的 `put`）。
- **不要给整页大小的元素做 `filter` / `backdrop-filter` / `mask` 的动画**；新增的 `box-shadow` 只放在不重绘的静态元素上（`.bk-shadow`、`.cov`），不要放在 `.pg`、`.stage` 上。
- **每帧变化的叠加层要自己一层**（`will-change: opacity`），否则透明度一变，底下的整张纸就跟着重画。
- 纸纹是静态的 SVG 背景，**不要**每帧重绘、不要在页上放 `animation` 的滤镜。
- 不要用 `getBoundingClientRect` 当页面里的 px（见上），也不要在一帧里反复“写样式 → 读布局”（书的话找空白是先量一次再算）。
- 翻页期间不要让别的东西满帧跑（字盘已暂停；新增的循环动画也要订阅 `stj-flip`）。
- 声音引擎在空闲时建好（`warmAudio`）：第一次 `new AudioContext()` 在 Windows 上占主线程约 60ms，别落在第一次点按里。
- 换页不要用浏览器的整页视图过渡：`base.css` 里 `:root { view-transition-name: none }`，否则 Astro 的 `ClientRouter` 每次换页都要给整个视口（含 WebGL 画布）截一张图。

**已知的剩余卡顿：**每个新页面第一次出现时（进卷、择域、摇签）有一两帧约 100–200ms 的间隔，**不在主线程**（`long-animation-frame` 的 `blockingDuration` 为 0，渲染阶段 ≤ 2ms），是合成与光栅化（新页面的文字字形第一次上屏、新建的图层）；之后再翻同一类页面就没有。

### 静止时

- 静止时：3D 字盘约 18 帧/秒（只有漂移）、悬停暂停时不画；书的话、墨与水、器物的 rAF 都只在有动静时才跑。换页前后 DOM 节点数 143（目录）→ 192（签卷入口），JS 堆（`performance.memory`）约 5–6MB。
