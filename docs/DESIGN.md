# 设计规范：古书 × 宣纸朱批 × 摇动控制

> 所有美术改动以本文为约束，改完逐项过 §9 的检查清单。
> 早先的方向"立轴 × 绀纸金泥"（深蓝纸、泥金字）已弃用：泥金在手机上难读，而朱批的"审阅"关系与作品立意直接对应。
> 2026-10-24 起，整个作品改成**一张书桌**（§19）：首页是一张桌子，正中一本合上的线装书，四周摆着各卷的器物；进卷之后书合着旁观，仪式用桌上的实物完成，书开口时封面掀起、字写在扉页上；仪式完了，书滑到桌子中央、摊开，里面是它替你写的**命书**，只用来读，翻页用 WebGL 做真的曲面卷页。早先的"摊开的古书、每走一步翻一页、左页右页、眉批栏"都已拿掉。

## 一句话

整个作品是一张**书桌**：桌上正中是一本合上的**线装书**（深靛封面、题签、四眼订线），四周摆着各卷的器物；**书就是大师，也是结果**。进卷之后，书合着旁观，退到桌子里侧；他开口时封面掀起一个角度，话是**字迹**，用行书写在露出的扉页上，全是墨，写完渗进纸里、淡去。**仪式在桌上**：木牌、纸笺、签筒、筊杯、龟壳铜钱、龟甲炭火，玩家用它们摇、掷、灼。仪式完了，书滑到桌子中央、翻开，里面是他替你写的命书：签文、卦、兆、判词、坦白、账本、命盘、四种结局，一页页翻着读。朱笔只留给印章、阴杯、最终判词与关键按钮。器物用**水墨写意**来画，但按**真实物理**来动。版式见 §19。

## 1. 为什么是书写的话

书的话是作品核心：大师一边看你求签，一边给你下判断。话是写在扉页上的行书字迹——上位者审阅、批示的位置，而且是毛笔写的：被观察、被评判的关系直接画进了视觉里。

（早先批语整句用朱色，后改为淡墨加朱色的圈点；2026-10-24 起书的话**全墨**，去掉了句尾的"〇"和朱色的数字，朱色只留给印章、阴杯、最终判词与关键按钮，这样朱色才一直是稀有的、最该被看见的。批语也不再有固定的天头栏，而是写在书开口时露出的扉页上，见 §4 与 §19。）

## 2. 纸面

| 元素 | 做法 |
|---|---|
| 宣纸 | 暖白 `#efe6d0`，叠纤维纹与低频的深浅斑驳；内容上方再盖一层极淡的纸纹，墨字与朱印也带纤维，像印在纸上。**不用 `mix-blend-mode` 混合整层内容**（Chrome 下出现色带，老旧内置浏览器风险更大）。噪声图案的频率 × 尺寸须为整数，平铺才无缝 |
| 书 | 一册线装书（§19）：合着时是深靛布面的封面、题签、四眼订线与四个残印位，右侧与下沿叠着层层纸边；读命书时摊开在桌子中央，纸是 Canvas 画的纹理，翻页是 WebGL 的曲面卷页。**不画朱丝栏、不画双线版框、不画方格** |
| 书的话 | 没有固定的栏：书开口时封面掀起，话写在露出的扉页上（见 §4、§19） |
| 天头栏与页脚 | 桌子的上方是天头栏（卷名、回书桌、源流与关于、通灵开关、昼夜印、声），下方是页脚（这一步的说明或这一页的脚注、步骤、按钮）；它们是坐在深色的案上的两条半透的深色栏，里面的字用纸白，两套主题相同 |
| 案与桌 | 桌面之外是"案"（`.an`），案上铺着深墨色的字盘（`#an-board`，见 §13、§18）；字盘之上是**书桌**：一块暖褐的木板（`.desk-plane`），书与器物放在上面（§19）；案与桌面沉进黑暗，书的周围被灯照亮 |
| 枯笔墨痕 | 每屏至多一笔大墨痕做构图骨架（SVG 路径 + 位移与条纹滤镜模拟飞白），标题可反白压在墨上 |
| 墨点 | 少量溅墨点缀，不超过 5 处 |

## 4. 字

字体族名集中在 `src/core/styles/base.css` 的四个变量里，换字体只改这一处（来源见 `tools/subset-fonts.py` 的 `DISPLAY` 与 `VOICE`）。

| 用途 | 变量 | 字体 |
|---|---|---|
| 卷名、标题、签名、签诗、卦名、结局名、印文 | `--f-display` | **汇文明朝体** Huiwen-mincho（日式明朝体的古籍味）。许可待确认，见 CLAUDE.md |
| 注（页脚的脚注）、账本旁注、坦白与通灵的"实话"（命书里） | `--f-kai` | **霞鹜文楷** LXGW WenKai Regular（OFL 1.1，v1.530）。**不用草书**：草书在手机上认不清 |
| **书的话**（书开口时写在扉页上的字）、你写在纸笺上的问题、命书扉页上问题的一行 | `--f-voice` | **龙藏体** Long Cang（OFL 1.1，开源行书），**全墨**，没有句尾的"〇"和朱色的数字；缺的字（如"筊"）回落到霞鹜文楷。选它的理由与四款行书的对照见 §19 "字体对照" |
| 正文、按钮、表单、账本 | `--f-text` | 思源宋体 Noto Serif SC（400，小标题与注的术语名用 600） |

汇文明朝体没有的字（如卦名里的"夬""姤"）回落到思源宋体；"筊"在两款字体里都有。字体都是按站内用字裁出的子集，改了任何中文文案后要重跑 `python tools/subset-fonts.py`；霞鹜文楷另有一个按 GB2312 一级字库裁的 `unicode-range` 文件，给通灵实时生成的字用。

**按钮、表单、导航、账本不用书法字体**，保证可读。手机端正文不小于 16px，说明文字不小于 14px。

书的话（`src/core/gloss.js`；文件名与 `ctx.gloss()` 沿用旧名）：书开口时，**封面掀起约 38°，字写在露出的扉页上**（见 §19），队列、去重与节奏的规则沿用旧的眉批槽：

- **文字先整句排好版，再逐字洇开**：每个字一开始就在 DOM 里，只是被动画延迟压着没出现，所以写字的过程中版面纹丝不动。
- **折行落在句读上**：按标点切成语段，每段是不可拆的一块，放不下时整段移到下一行，不在词或"3.9 秒"中间断开；不用省略号截断。
- **一次只写一句**：扉页上只留正在写的这一句；写完停一会儿（1.5 秒加每字 85ms，至多 3.6 秒；后面排着队时只停 0.5 秒），渗进纸里（`opacity` 与 `filter: blur` 一起在 2 秒里退去，`is-sink`）；被顶替时 0.3 秒快速淡出；队列里没有下一句了，余韵 0.7 秒，封面落回。
- **同一类话只留最新一条**（`key`；如连点"功名、尘缘"时，新的顶替旧的，不排队）；后面排着队时写得更快、停得更短。
- **全墨**：没有句尾的"〇"，数字不点朱（`marks.js` 已删除）；警示句的着重点是墨。朱色规则对**书的话**之外不变：印章、阴杯、最终判词、关键按钮。
- **减少动效**：封面不掀，不逐字洇开，整句淡入、淡出（`.is-plain`）。
- 书的话**不再找空白**（没有"两页"可避让），不再翻页暂缓，也没有"回看写下的页时不开口"（没有翻页了）；读命书时不开口。

## 5. 器物：灯下的实物（2026-10-25 改）

书桌与器物不再是写意的图，而是**灯下的实物**：一个 three.js 场景、一个 renderer、一套灯光（`src/core/scene/desk3d.js`），桌子、书、器物同在其中。所有几何体与材质都在运行时生成，不用位图、不用外部模型。

- **视角**：相机在桌子正前方，55° 的三分之四俯视（`ELEV`），按窗口自动框住桌子；所有器物同一个视角。尺度按厘米：桌 112×72、书 26×36（竖放时）、签筒高 22 径 10、龟壳口径 12、铜钱径 3、龟甲 15.6×21.8；首页里器物略缩小（0.82–0.95），进卷后走到面前放大一些（像拿到手里）。
- **光**：主光是左上前方的一盏灯。**夜**：暖色聚光，光池落在书的周围，四周压到很暗，阴影软（VSM）；**昼**：窗光，偏冷，整体亮一档，阴影更软、更淡。两套光是同一组灯的不同参数，切主题时 0.9 秒平滑过渡。桌上每件东西都有软接触影，再加真实的阴影贴图。
- **桌面**：旧漆木，`paint3d.js` 的 `paintWood` 在 Canvas 里画：四块拼板、不规则的年轮、低频的明暗磨损、磨亮的地方（粗糙度低）、孔隙与划痕，配凹凸与粗糙度图和一层清漆。桌沿有厚度与倒角（ExtrudeGeometry）。桌子在案（字盘）上投一圈软影。
- **书的封面**：昼里是低饱和的旧靛蓝（布纹粗细不匀、边角磨得发灰发白），夜里随灯补一点蓝，看上去仍是深靛（`book3d.js` 的 `tintCloth`，随主题平滑变）。
- **卷名小木签**：14.4×4.5 厘米，1440 宽下卷名约 25px、全称约 14px（`paintTag` 按木签高度取字号）。
- **材质**：签筒是竹，带竹节与手握的包浆，筒身一方朱印；签是竹片、签头墨点；铜钱是旧铜，方孔，字面浮凸、带铜绿与磨亮的边；龟壳是六边盾片的背甲，琥珀与深褐的斑，**椭圆**（前后比左右长 26%）——首页里**壳口朝下扣在桌上**，露出整个背甲的盾片纹与拱起的弧度（俯视的机位下，壳口朝上看起来是一只碗），进卷后翻过来（0.8 秒），壳口朝上、略朝玩家，里面是三枚钱；龟甲是骨，背面凿着六处钻凿，正面是兆；筊杯是红漆的新月形木块（一面平一面凸）；星盘是铜与漆，刻度是细线；鸟笼是竹篾；历书是素纸；砚是深石。
- **一件器物从头到尾只有一套表现**：首页、卷首、仪式中是同一个 3D 物件，只是位姿（位置、大小）与状态不同。仪式的版面（DOM）给出"落脚处"（`.piece-slot`，不画任何东西），器物走到它在桌面上的位置。
- **首页的辨认**：每件器物前面的桌上有一块小木签，常显卷名与全称；开卷的亮，未开卷的蒙灰、签是灰的并写"未开卷"。悬停：器物微微抬起、被灯照亮，上方浮出一张简介笺（不挡书）；键盘 Tab 到器物等同悬停，有可见的焦点框。
- **交互**：指针由画布用 raycaster 拾取，转给器物的替身按钮（看不见、可聚焦，键盘与读屏用），所以摇、掷、灼的物理与输入方式（拖动、按住、晃手机、空格）不变。物理仍是各卷自己的二维模拟，画面交给 3D 的 view（`tube.js`、`shell.js` 的 `view` 参数；灼龟见 `scene/pieces/bu.js`）。
- **退回方案**：窗口 < 960px、减少动效、WebGL 不可用、`?scene=2d` 时，仍是 SVG 的器物与 CSS 的桌面。2D 同样在器物前放一块常显卷名的小木签，未开卷的暗下去；签筒只有一种画法（首页与摇签是同一张水墨）。手机上是俯视的书桌角：书在上，器物在下排成一行，可横向滑动。
- 桌上的说明与记录（掷筊的规矩、爻的算法、读兆的文字）写在摊在桌上的纸笺上（墨字、宣纸底），不直接写在木头上。
- 物理与输入见 §6。

## 6. 摇动控制

- 手机加速度计为主输入：倾斜决定器物倾角，晃动力度累积成"能量"；iOS 在第一次点击时请求权限。
- 回落：按住器物左右拖动；按住不动时器物自己轻摇；键盘按住空格。
- 器物本身就是控件，文字按钮只作回落与无障碍入口。
- 按能量出结果，不按计时。
- 每次碰撞同时有画面、声音、震动（安卓）。

物理参数：重力 2400 px/s²，倾角弹簧 k 90 / 阻尼 12，落地恢复系数 0.35，摩擦 0.8，固定步长 1/120 秒。一次摇签 2–4 秒；签落地到签诗出现不超过 1 秒。"减少动效"时跳过飞行与弹跳。

（部分借鉴 InkView 的设计原则，MIT：https://github.com/qybaihe/inkview ；未采用其 PNG 素材，因本项目不引入位图）

- 书法字体用在按钮、表单、账本上。

## 8. 墨与水（2026-09-30，2026-10-24 大幅缩小）

墨与水的画布（`src/core/ink.js`）原来盖在摊开的书页上，随点按、换屏、落签落墨。**书合着之后，它只剩一个用处：案上字盘被点一下时，在那里洇开一团墨**（`board3d.js`、`board.js`；§13、§18）。书上不再落墨：书的话是逐字洇开的字迹（§4），玩家写的问题被纸吸进去（`.ask-written.is-soak`：糊一下、字距略松、再沉成一行淡墨，1.5 秒），命书是画好的纹理。

约束沿用：

- **质感取"水洇在宣纸上"**：边缘柔和的淡墨晕，加细而淡的水纹。**不画放射的细线（像蜘蛛腿），不画吊着的细线（像蛛丝）**。
- 画布只在有动静时才跑 rAF，静止时零开销；运动中的东西不用 SVG 滤镜，靠柔边的径向渐变叠层。
- "减少动效"下：画布层整体关闭（`createInk` 返回空实现）。

## 9. 每屏完成前的检查

1. 底是宣纸（页与纸笺）与暖褐的木桌，**没有朱丝栏、版框与方格**；书有封面、题签、订线、纸边的厚度；
2. 朱只用于印章、朱批圈点（变爻的〇、阴杯）、最终判词与关键操作按钮；**书的话是墨**（行书，没有句尾的〇与朱色数字），命书里的旁注、坦白与注的正文也是墨；
3. 字体分工对（§4）：标题、签名、签诗、卦名、结局名、印文用汇文明朝体；书的话与问题用龙藏体行书；注、旁注、实话用霞鹜文楷；正文、按钮、表单、账本用思源宋体，对比度足够；
4. 器物是水墨画法，能摇、能按住、能用键盘；
5. **仪式在桌上，书合着旁观，结果写进命书**（§19、§20）：器物摆在桌上，**主按钮在桌面下方中央的按钮槽里**，页脚只有两行（说明；步骤与存疑）；源流、关于、通灵开关在天头栏，页脚不重复；
6. 读命书时，**翻页只通过点页、拖页角、方向键**，没有"上一页 / 下一页"按钮（2D 退回方案里才有两侧的翻页热区）；**减少动效、手机、WebGL 不可用下退回 2D 书页，功能等价**；
7. 内容放不下就续页（坦白、账本，排版在做页描述时完成），单页里不出现滚动条（长文的源流与关于页例外）；注是命书页脚的脚注，最多三条，每条一行；
8. 桌面 1440×900、1366×768 与手机竖屏 375px 宽下都完整可见；

12. 3D 场景符合 §18 与 §19：页面不可见时不渲染、静止时不逐帧画、dpr ≤ 1.5；手机宽度、`pointer: coarse`（字盘）、减少动效、WebGL 不可用时退回 2D。

## 10. 命盘与分享图（2026-10-02）

- **命盘的画法（2026-10-24）**：命盘不再逐帧织出来，也不再单独画在网页上，而是画在命书的一页上、也画进分享图；两处共用 `loom.js` 的 `weave()`，它把相邻 7 段并成一笔、丝的总数封顶 360、每画 5000 笔让出一次主线程（原因见 §19 "保存卡死的根因"）。
- **命盘丝线**：每根丝带"笔压"，沿途粗细、浓淡随笔压起伏，最轻处偶有飞白断口；收笔处（右端）渐细渐淡。线头用平头（圆头相邻叠加会叠出一串小珠）。每一束丝下垫一片淡墨，被弃掉的那一掷更淡；阴杯的右半，淡淡带朱。
- **分享图**：下半截衬一幅算法生成的淡墨远山（三层山脊由远及近渐浓，层间一抹云气，脊线是断续枯笔，山腰几笔短皴），只画在内框之内，命盘与二维码压在山前。山脊由一维值噪声叠三个八度生成，种子与这一局相同，所以每个人的山都不一样。网页上不加山：每屏至多一笔大墨痕。
- 参考过但没采用的开源库：rough.js（铅笔白板的涂鸦感，不是木版）、shan-shui-inf（只借思路，远山自己用噪声画）、WebGL 流体模拟（手机耗电、内置浏览器兼容风险，而且这里的媒介是纸不是水）。

## 13. 案上字盘与盖印（2026-10-22，2026-10-24 改）

### 案上字盘

书之外的"案"是一盘**反刻的阳文活字**（书与字盘用 `transition:persist` 常驻，换页、换卷都不重建 three.js 画布；字盘的用字按**首次载入的页面**定）：深墨底（`#2b2620` 到 `#14120f` 的径向渐变，盘边再收暗），每个字是一枚浮雕般的铅字，字身镜像，亮边在左上、暗边在右下，字色只比底亮一点点（低对比，不抢书页）。桌面上它从桌子（暖褐的木板）的四周露出来；手机上桌子几乎占满全屏，只在天头栏与页脚的半透底下隐约透出。

| 项 | 做法 |
|---|---|
| 实现 | `src/core/paper/board.js`：按案的尺寸把一盘字**一次性**画在离屏画布上（桌面格 38px，手机 22px；整盘镜像，行内次序也是自右向左；约 5% 的位置是空铅），上下两幅相同，再用 CSS `transform: translate3d` 循环滚动一个 `tileH`（约 9px/秒）。滚动时不重绘、不跑 rAF；窗口尺寸变化后（防抖 250ms）重画一次。画布最多 dpr 1.5，纹理总量压在约 9M 像素以内 |
| 字 | 一律用思源宋体（活字感），只取 BMP 里的汉字，扩展 B 区以后的字一律不用，免得没有字形时回落到系统字体、显示成方框。部首表里思源宋体没有字形的字已经事先剔出（`shuowen-bushou.js`） |
| 按卷取字 | 路径第一段是卷 id 时，取该卷模块的可选字段 `zipan`（字符串，或返回字符串的函数，可异步，见 `src/juan/index.js`）；没有 `zipan` 的卷、书桌（首页）与静态页，用《说文解字》540 部首（`src/core/paper/shuowen-bushou.js`，公有领域）。各卷用什么：签＝六十一首签诗，卦＝《周易》经文，卜＝甲骨卜辞释文，字＝《说文》，历＝历书宜忌用语；书桌＝《说文》部首 |
| 悬停与按住 | 鼠标悬停在字盘上，整盘暂停，移开恢复（`:hover`，仅 `hover: hover` 设备）；触屏按住暂停，松手恢复；页面隐藏时暂停（`visibilitychange`） |
| 点一个字 | 那里"拓"出一枚**小朱印**（朱色，阴文，字是拓回来的正字），随那枚铅字一起滚；同时洇开一团墨（`ink.js` 的 `wash`，在深底上用比底更黑的墨，水纹是一圈淡淡的亮痕）。朱印停 5 秒后淡去，最多留 8 枚。朱印另放一层、盖在墨晕之上，与字盘同一段动画，所以暂停与滚动始终同步 |
| 减少动效 | 字盘静止；点击仍落朱印，只是没有动画，也没有墨晕（`createInk` 返回空实现） |
| 约束 | 字盘本身是墨色，不用朱；只用 transform 与 opacity；静止时零开销（实测静止 3 秒内页面脚本的 rAF 调用为 0，墨晕散尽后也为 0）。书桌放在字盘上，天头栏与页脚是盖在字盘上的两条半透的深色栏 |

### 印章按下

所有朱印按钮（`Seal.svelte`）共用：

1. **按下**（`:active`）：印往下压，`translateY(2px) scale(.9)`，略暗，60ms。
2. **松手**（`click`，键盘激活同样）：`.is-print` 播 0.42 秒的一震（回弹到 1.05，再左右各偏 1px，落定），同时印边晕开一圈朱色（`box-shadow`，最远 `--s × 0.13`，淡去）。
3. 多数印按下就换屏、页脚里的按钮随屏换掉，一震还没演完：这时在原处留一枚**影印**（克隆的印，不接事件，挂在书或页脚上）把这一震演完再移除。
4. 毛边滤镜 `#seal-rough` 的区域放宽到 ±14%，印迹那一圈才不会被截掉。
5. 减少动效下全部跳过。

## 14. 卦卷的器物与卦画（2026-10-22）

- **龟壳与铜钱**（`src/juan/gua/shell.js`）：与签筒同一套做法（§5、§6）。龟壳是淡墨晕染的壳身，壳上几笔盾片的接缝，一方朱印；铜钱用旧铜的低饱和色（灰褐，不用金色），墨线勾边，字面是“天机通宝”四字，背面光素，只有星与月。运动中的器物不用 SVG 滤镜。

- **命盘的织法**：一爻一束丝；少阳平直，少阴在中间分开，老阳胀成一个圈，老阴在中间交叉；变爻的中段带一点朱。

## 16. 统计与隐私

作品本身讲的是"被算法旁观"，所以统计必须比作品里的大师老实：收什么、不收什么，都要写在玩家看得见的地方（账本页、关于页），并且与代码一致。

- **上报**：每局结束一条，只有卷、领域、结局（遵逆破迷）、本局结果标识（签号、卦序或兆象）、用时分档、是否写了问题、问题的类别（语气、主题）、昼夜主题，日期由服务端按天填。字段与枚举在 `src/core/stat-schema.js`，服务端一律白名单校验。
- **不收**：问题原文、IP、UA 原文、指纹、cookie、跨局的设备编号。同一个人的两局无法连起来。本地账本与上报的数据没有关联，也不会被上报。
- **IP 的用法**：只在服务器内存里哈希，作为每天的次数计数键写进 `hits`（单 IP 60 局、全站 5000 局，超限静默丢弃），隔天清理；不写进 `rounds`。
- **问题归类在浏览器里做**（`src/core/question-class.js`）：语气沿用观人术的犹豫、困惑、期待；主题是工作、学业考试、感情、家人、健康、钱财、搬迁出行、其他。词表是本作自己的设定，只是关键词匹配，会判错，不得当作语义理解来写。
- **对玩家说的话**：结局坦白里大师用第一人称说一句聚合数字（"今天来问功名的，有 35%"），全墨（命书的坦白页，不点朱）。只用当天或近 7 天；不足 20 局不说数字，改说一句不带数字的话；读不到聚合（离线、本地预览）就什么也不说。模板集中在 `src/core/peer-lines.js`。
- **隐私说明**：账本页说明"细节只在本地，另有一条匿名统计"并列出字段；关于页写全字段与限流用 IP 哈希的事，并说明通灵模式是例外（问题会发给 AI）。改上报字段时，这两处和本节一起改。
- **作者统计页** `/admin/`：令牌放 `Authorization: Bearer`，服务端与 `STATS_TOKEN` 常量时间比较，未设置一律拒绝；令牌只存 sessionStorage；页面 noindex（meta 与 `public/_headers`），不链接；图表用 SVG 自己画，不引图表库。页面自带样式，不走公共纸面。
- 带 `?debug` 的页面不上报。

## 17. 双主题：宣纸与乌金拓

| | 宣纸（浅色，默认之一） | 乌金拓（深色，书的夜间版） |
|---|---|---|
| 意象 | 宣纸、墨、朱批 | 夜里灯下的一册：**书仍是纸色**（稍暗，带一点灯下的暖黄），字仍是墨；案与字盘沉进黑暗，书上方有一盏灯 |
| 纸面 | 暖白宣纸，纤维与深浅斑驳 | `#d3c297`，纹理同浅色，只是底色换成 `--paper`（取消早先的磁青纸：看起来像负片，也与"书是纸做的"不一致） |
| 字色 | 墨 | 墨（`#1a1510`）；朱字更深（`#861b16`）；泥金只在书外的装饰上；正文对纸约 10:1（AA） |
| 墨晕 | 淡墨 | 淡墨（书上落的墨昼夜都是墨，`ink.js` 的 `inkRgb()` 不再随主题变） |
| 案与字盘 | 深色的案，暖光 | 字盘整体压暗（`filter: brightness(.62) saturate(.55)`），再叠 `.an::after` 的两层渐变：一团暖光落在书与近处的桌面上（`--lamp-rgb`、`--lamp-a`），四周收进黑暗（`--dim`） |

- **机制**：`<html data-theme="light|dark">`。`Paper.astro` 的 `<head>` 里有一段内联脚本，**在首帧之前**设好它：先读 `localStorage['stj-theme']`，没有就跟随 `prefers-color-scheme`，读写都包 try/catch。之后系统配色变了，若玩家没手动选过，会跟着变。统计等代码读这个属性。
- **开关**：天头栏右侧，与"声"并列的一枚小朱印（印章式），写当前的主题——"昼"或"夜"，点一下换成另一个。`aria-label` 写明点了会换成什么。逻辑在 `src/core/theme.js`（`setTheme`、`onTheme`、`inkRgb`）。
- **颜色全走变量**（§3）。SVG 里的器物（签筒、龟壳）用 `fill="var(--obj-ink)"` 这类写法。**案上的器物坐在深色的桌面上，不论昼夜都用"夜里"那一套器物配色**（`.desk-items` 里局部重定义 `--obj-*` 与 `--ink` 一组变量）。书页的纸边层次（`--edge-a/-b/-line`）与向书脊渐暗的程度（`--gutter`）也是变量。
- **天头栏与页脚**坐在深色的案上，两套主题里字都是纸白（在 `.topbar, .botbar` 里重定义 `--ink` 一组变量）。
- **深色下只有字盘，没有别的飘动的东西**：早先深色下的"写经绢帛"飘带已删掉（浅色本来就没有，两边一致）。
- **Canvas 跟着换**：2D 字盘（`board.js`，换主题时重画）、3D 字盘（board3d）。**书页上的 Canvas（墨与水、命盘）昼夜都按纸色来画**（书是纸色），所以 `inkRgb()` 与 `weave` 不再随主题变。卦画是 SVG 变量；签卡是 CSS。龟甲是骨色的实物，两套主题下保持不变。
- **主题与 ClientRouter**：ClientRouter 换页时会把 `<html>` 的属性换成新页面的，`data-theme` 会丢。`Paper.astro` 的内联脚本在 `astro:before-swap` 里把当前的 `data-theme` 补到新文档上（也补 `theme-color`），并把动态加载的样式表带过去。
- **分享图保持浅色宣纸**：它是要带走的一张纸。`weave` 指定 `width`（离屏重织）时一律用浅色。
- **厚度**（CSS，克制，文字始终正面朝向）：龟甲卡悬停时随鼠标透视倾斜 ≤ 4°（`core/tilt.js`，仅鼠标，减少动效下不做）；朱印按钮有"印身"（下缘一道深朱）与软影，按下时下沉 3px、印身压平，松手的一震不变；小木牌（回书桌、声）有木纹、亮边、暗边与下缘一线厚度。签筒、龟壳、龟甲只补光影，不改交互和物理。

## 18. 3D 场景层

three.js 只用于场景层（现在只有案上的字盘），文字、按钮、印章仍是 DOM。three 是 npm 依赖，**只在真正要用时动态 `import()`**（`board.js` 里），包是独立的一块，不进首屏。

### 3D 铅字字盘（取代 2D 字盘）

- `src/core/scene/board3d.js`：**一个 InstancedMesh**（一份盒子几何，几千个实例），每个字是一块有厚度的金属活字。字形图集（`atlas.js`）在运行时用 Canvas 画出反字，R 通道即高度；字面的凸起在着色器里对高度图取差分得到法线，边缘倒角在着色器里弯折法线，顶面受光、倒角出高光。不为每个字单独建几何体，不用位图素材。
- 字来自每卷的 `zipan`（同 §13）；约 5% 空铅；深色下约 4.5% 的字泛泥金。
- **交互**：鼠标移过，附近 3.4 格内的活字按距离抬起（每块略有差别，参考木盒里被抬高的活字）；点一下，那一块按下去，原地"拓"出朱印（阴文正字，在着色器里把图集沿 x 翻回来），并洇开一团墨晕（`ink.js`，画在其上的 2D 画布）；朱印停 5 秒后淡去，最多 8 枚；朱印、抬起量跟着那块活字一起滚。
- **滚动**：整盘约 0.24 格/秒向上滚（与 2D 约 9px/s 相当）；悬停（或按住）暂停；整盘只上移一格时才重写数据。
- 浅色：旧木盒里的铅字（灰褐金属，暖光）；深色：墨底，铅字泛冷光，偶见泥金。

### 字盘为什么没有并进同一个 renderer（2026-10-28 评估）

评估过，**保持两块画布**：① 字盘是整个站点常驻的底层，用 `powerPreference: 'low-power'`，静止时一帧不画、漂移时约 18 帧/秒；桌子的循环在翻页与演出时是 60 帧，并进去，每一帧都要把几千个实例的字盘再画一遍（读命书时现在是暂停字盘来给翻页让出合成器的）；② 字盘有自己的着色器、相机（视差倾斜）、图集与朱印的 2D 墨晕层，退回条件也不同（触屏、减少动效、手机都退回 2D 字盘，而桌子是另一套条件）；③ 桌子的灯与 VSM 阴影的视锥只照桌面，字盘并进去要么扩大阴影视锥（分辨率摊薄），要么单独关阴影，两头都不划算。收益只有少一块画布，代价是两套生命周期搅在一起。

### 性能约束

- 页面不可见（`visibilitychange`）时停止渲染，并取消计时器。
- 渲染节奏：有抬起、按下动画时跟随 rAF（落定后立刻停）；只有漂移（滚动）时约 18 帧/秒（`setTimeout` 50ms 再 rAF）；只剩朱印淡出时约 30 帧；**悬停暂停且没有动画时一帧不画**。
- dpr 上限 1.5。图集最多 1024 字（1536² 画布）。尺寸变化后只在需要更多格子时重建网格。
- 只重写动过的块的实例属性；整盘上移一格时才整体重写。
- 调试：`?debug` 后有 `window.__scene`（`stats()`、`step(dt)`、`hover(x,y)`、`click(x,y)`）。

### 退回 2D

以下任何一条成立，一律用 `board.js` 里的 2D 字盘（§13，功能等价；深色下按新配色画）：

1. 手机宽度（视口 < 960px）；
2. `pointer: coarse`；
3. `prefers-reduced-motion`；
4. WebGL 不可用，或three.js 加载、初始化失败、上下文丢失。

条件在运行中变化（窗口跨过 960px、系统设置变了）时会自动换过去（防抖 200ms）。`?scene=2d` 可强制 2D。

- **封面**：深靛布面（`--cover`，纵横交织的细线做布纹，CSS 渐变，不用位图），比书页大一圈；书脊一侧向里凹。**左上贴一张题签**：一张窄纸，竖题"演算天机"，用 `--f-display`。**书脊一侧有线装订线，四眼订法**：四个订孔，象牙色的丝线沿书脊上下贯穿，在每个孔处绕过书脊，上下两端各有一道包角的斜线；丝线压过书脊，下面有一层深色的影（SVG）。

- **不要在 `.bk-body` 的祖先上放 `filter`、`overflow: hidden`、`mask`**：会把 `preserve-3d` 压平。

### 书的话与书自己的动作

- **书说话时，封面掀起约 38°**（`data-lift="speak"`），字写在露出的扉页上，写完封面落回。扉页是一张从书里露出一截的**纸笺**（`.bk-slip`，在书的平面里，落在掀起的封面旁）：一次只写一句，一笔一笔洇开（`ink-soft` 动画，每字 46ms；后面排着队时 28ms 或 14ms），停一会儿（1.5 秒加每字 85ms，至多 3.6 秒；排着队时 0.5 秒），渗进纸里淡去（2 秒）；队列里没有下一句了，余韵 0.7 秒，封面才落回。**队列、去重（`key`）与节奏沿用旧的眉批槽**（`src/core/gloss.js`；文件名与 `ctx.gloss()` 沿用）。**不再找空白**：扉页本来就是空的；不再翻页暂缓、回看不开口（没有翻页了）。读命书时书不开口。
- **书的字是行书，全墨**：`--f-voice`，**龙藏体** Long Cang（OFL 1.1）。**句尾的"〇"和朱色的数字去掉了**（`marks.js` 已删除，书的话里数字就是墨）；警示句的着重点也是墨（`text-emphasis` 用墨色）。朱色规则不变，只给印章、阴杯、最终判词（结局名与印）、关键按钮、变爻的圈点。
- **纸笺的尺寸按书的缩放反着算**：写字的纸笺在书的坐标里，`calc(21px / var(--bs))` 之类，所以不论书缩成多大，屏幕上的字号不变（桌面 26px，倾斜的书页平面会把它在竖向压扁约三成；手机 18px）。
- **减少动效**：封面不掀（`--cv: 0`），纸笺直接浮在封面上方（`translateZ(40px)`）；不逐字洇开，整句淡入、淡出。
- **手机**：书缩成顶部的小图标（`--bs: .24`），书说话时，旁边展开一条字迹（纸笺横在图标右边，宽 `100vw - 112px`）。
- **书的动作**（`book/fx.js`，作用在合着的书 `.book` 上）：犹豫（静止八秒）→ `is-tremble` 轻颤 0.85 秒；重求、重起、再灼 → `is-riffle`：封面掀到 62° 停一下再落（1.2 秒），同时我说一句"我合上这一页，再翻开一页新的"；按下存疑印 → `tear`：封面被一道锯齿线裁成两半，错开微转（0.9 秒），停 0.7 秒，复原；结局 → `is-thud`：书沉一下（0.5 秒）。

### 命书：只用来读

仪式一完（`finishRound` → `ctx.show('end')`），结局屏的 `<Spread book={…}>` 登记命书，Codex 进入 `reading` 阶段：书滑到桌子中央、放大、封面翻开；同时 `Reader.svelte` 开始画页（字体加载完才画，一页一页画，不堵主线程），画好交给桌上的书（3D）或挂进 DOM（2D 退回）。**书里是它替你写的命书**，依次是：

| 页 | 内容 |
|---|---|
| 扉页 | 这一卷（卷名大字、全称）、所问方向、你写的问题（行书）、日期、一枚朱印"命" |
| 结果页 | 签：签文（号、名、级、竖排签诗）与解签；卦：卦（卦画、卦辞）、解卦、六位二进制；卜：兆（刻了辞的甲，兆纹与刻辞和桌上的兆图是同一份数据同一个绘制函数）与解兆 |
| 过程记录 | 签：掷筊（每一支签、每一杯，阴杯朱）；卦：起卦（每一卦的六爻，弃掉的淡）；卜：灼卜（每一灼的钻凿、按住的时间、手抖、读出的兆） |
| 判词 | 结局的印、名（朱）、引语、诗、"不过，在你……的时候，我也在给你算命" |
| 坦白 | 旁批里的数字是怎么从你身上算出来的，加"和你一样的人"那一句；一页放不下就续页 |
| 通灵 | 请大师细说之后，AI 的回话（只有接通灵的卷、请过的人才有；请求的按钮在页脚） |
| 账本 | 行为账本，每行一条旁注，最后是匿名统计的说明；放不下就续页 |
| 命盘 | 由这一局的行为数据织成的锦（`loom.js`，画在页上）与图例 |
| 四种结局 | 只揭示得到过的 |

- **页是 Canvas 2D 画出来的纹理**（`book/paint.js`、`book/pages.js`、各卷 `book.js`）：设计尺寸 600×840（5:7），画布按 dpr 放大（1.25–1.5 倍，最多 900×1260，约 3–5MB 一页）；**字体（汇文明朝体、思源宋体、霞鹜文楷、龙藏体）要等 `document.fonts.load` 之后才画**。复用并扩展分享图（`core/poster.js`）：纸、印章、折行、墨色；卦画是分享图同一个 `figure()`，兆是同一个 `drawFigure()`，命盘是同一个 `weave()`。字全是墨，朱只在：判词的结局名与印、阴杯、变爻的圈点、改判、扉页的印。
- **长内容先排版再分页**（`book/flow.js`）：坦白、账本一页放不下，排版在做页描述的时候用一块空画布量字宽完成（中文字宽固定，不必等字体），所以总页数在翻页之前就确定。
- **页会重画吗**：每一页有 `sig`（内容的签名），页描述每次重新生成，Reader 只重画 `sig` 变了的页（通灵回话、"同类人"的数字回来）；**翻页时不重画任何纹理**。
- **注写成页脚的脚注**：每一页有 `zhu`（这一页用到的术语）；页脚取左右两页的术语，最多三条，每条一行（术语名、注、出处标签：古籍 / 民俗 / 原创）。注的数据仍在各卷 `zhu.json`；不再有点术语浮出纸条。
- **保存**：页脚的"保存这一签 / 卦 / 卜"继续用**分享图**（一张长图，带二维码），没有改成导出命书的某一页：分享图是一张可以独立传出去的图，命书的页是"读的"，二者的用途不同。同一局里图只画一次（再点"保存"直接给现成的）。
- **页脚的按钮**（`book/ReadFoot.svelte`）：合上（回书桌）、再来一次、请大师细说（通灵）、保存。

### 命书的翻页：WebGL 的曲面卷页（`book/three-book.js`、`book/curl.js`）

- **一张纸是一个细分的平面网格**（40×14 格，561 个顶点）。**按拖动点做圆柱或锥面的卷曲**（`curl.js` 的 `bend`）：卷曲线是一条过 (t, 0)、法线 n = (cos a, sin a) 的直线；线之前的纸平放；线之后的纸沿法线方向卷在一根半径 R 的圆柱上（弧长 u 对应角 θ = u / R；θ ≤ π 是卷起来的半圈，θ > π 翻过去贴在另一侧）。**锥面**：R 随沿线方向的坐标变化，一头紧、一头松；被拖的角斜着领先（a 随纸角偏上偏下而变）。a、锥度、R 都乘 sin(πp)，所以翻开（p=0）与翻到底（p=1）时是规规矩矩的平面，翻到底是 x 的镜像（读过的那一叠）。订口处纸向下凹 3.5。（`curl.js` 不知道左右装：右装是 `book3d.js` 把整本书镜像摆出来，纸的 uv 在 `sheetGrid(…, mirror)` 里反过来，字才是正的。）
- **光照与投影**：用桌上同一盏灯（§5；夜里聚光、昼里窗光），纸是 `MeshStandardMaterial`。**正在翻的纸投影**在下面的书页和桌上；翻的那张纸不接自己的影，没翻的纸只接影；法线每帧按变形后的顶点重算，所以卷起来的纸亮部、暗部随弧面变化。
- **背面透出少许正面的字**：纸的正反各贴一张纹理（正面是第 2i 页，背面是第 2i+1 页），**同一张纹理在着色器里被另一面再取一次**，按 10% 压在底色上（`onBeforeCompile` 改 `map_fragment`）；背面的纹理在着色器里左右翻回来（从背面看，纸是镜像的）。不另造合成的画布，不多占内存。
- **点击翻页与拖页角**（`Reader.svelte` 的指针处理）：点未读的那一叠（纸坐标的右半，3D 右装时在屏幕的左边）往后翻、点读过的那一叠往前翻；按下后拖过 8px 就是拖页角：指尖用射线落到书页的平面上，换成翻开的程度 p = (W − x) / 2W，并记下手的速度；**松手时 p + v × 0.16 > 0.5**（过了中线，或者甩出去了）就翻过去，否则弹回。方向键同样翻页：**3D 的右装书从右往左读，←是往后翻、→是往前翻**（手感是把左边那一叠一页页翻到右边）；2D 退回（左装）仍是→往后、←往前。最多翻到最后一页真正的内容（后面的空白不翻）。
- **惯性与回弹**：弹簧积分（`spring`，固定小步）：点击翻页 ω = 7.2、ζ = 0.74，约 1 秒落定；松手后 ω = 11、ζ = 0.62，带着手的速度；到 0 或 1 的头上碰一下，反弹系数 0.28。
- **纸的层次**：纸叠在书口（右侧与上下沿）的三面纸边上（细纹的纹理，高度随这一叠的纸数变）；一叠纸的总厚与合着时的书页一样（2 厘米，纸数多就每张薄一点），所以书翻开前后厚度不跳。未读的一叠下面是底板，读过的一叠下面是翻开到底的封面，板内是旧纸色的衬页。第一页（扉页）单独在未读的一边（3D 右装时在屏幕的左边），另一边是封面的衬页；第 k 个对页是第 2k-1 页在右、第 2k 页在左（3D 右装，先读右边再读左边）。
- **性能**：**静止时一帧不画**；翻页时每帧只重算正在翻的那一张纸的顶点与法线（561 个）并重画一遍场景，**不重画任何纹理**（纹理在 `setSheets` 里一次上传，放在演出开始之前，免得第一帧在演出里卡住）；阴影贴图只在有动静时更新；dpr ≤ 1.5；字盘在读命书时暂停（`stj-flip`）。**渲染循环是桌子的**（`desk3d.js` 的 `addTicker` / `invalidate`），纸没有自己的 renderer。实测（headless Chrome + d3d11）：翻一页 0.98 秒约 236 帧，渲染中位数 0.6ms、p95 0.9ms；演出与翻页之后静止 2 秒 0 帧。
- **退回方案**（功能等价）：以下任何一条成立（即 3D 书桌退回 2D，§5），用 DOM 里的 2D 书页，不用 WebGL：① 手机宽度（< 960px），**单页**，点左右两边、滑动或点上一页下一页的边翻页；② `prefers-reduced-motion`，两页并排，直接切换（不播翻页动画）；③ WebGL 不可用，或 three.js 加载、初始化失败：两页并排，翻页是平移淡入（0.45 秒）。页的画布与 WebGL 用的是同一批；点两侧边、方向键翻页；脚注照常。窗口跨过手机宽度、减少动效变了，会自动换过去并回到扉页。
- **调试**：`?debug` 后有 `window.__reader`（`engine`、`book`、`mode`）、`window.__desk`（`desk`、`book`、`pieces`、`overlaps()`）、`window.__ctx`（让书说话：`__ctx.gloss('…')`）。`window.__desk.overlaps()` 是穿模检查，见“穿模检查”一节。

### 同一本书：原地摊开（3D 书桌，2026-10-28）

读命书不再另起一块画布、另一本书：**桌上合着的那本书原地翻开，书页就是命书的纹理页**。

- **纸挂进书里**：`three-book.js` 导出 `createSheets(desk, parent, …)`，纸挂在 `book3d.js` 的 `sheetsRoot`（书脊上，x 向书口、y 向书头、z 向上，一个单位 0.0504 厘米）。没有自己的 renderer、相机与循环。`book3d.js` 持有它（`book.reading`），`Reader.svelte` 只负责画页纹理、接手势（点页、拖页角、方向键，数值与惯性不变）、读屏朗读；Reader 卸载时纸仍属于书，由书收（`leaveReading`）。
- **相机**：`desk3d.js` 的 `cameraTo('reading' | 'table', ms)`。读命书时相机更陡（63°）、更近，注视点落在摊开的书上，按窗口把整本摊开的书框进天头栏与页脚之间（`frame()`：和框桌子是同一套迭代，只是给出的点与画面的边界不同）；推近 1.3 秒，三次缓入缓出（`smoothstep`）。读命书时书脊在桌子正中（`POSES.reading`：镜像后世界 x = pose.x + 12.5·s，取 pose.x = −18.75、s = 1.5）；翻开的两张竖页并排，读命书机位把它们框进天头栏与页脚之间。
- **摊开的演出**（`book3d.js` 的 `beginReading`，纸一画好就由 Reader 起，实测约 2.2 秒，**点一下、按回车/空格/Esc 就跳过**，直接到“翻开、第一个对页”）：① 说话时掀着的封面先落回（0.12 秒）；② 封面绕书脊翻开，0.85 秒，`easeInOutCubic`，起时一声纸响（`audio.js` 的 `rustle`），落在桌上一声闷响（`flop`）；翻开的角度过 1.6 弧度后封面落到与底板齐平，书脊的布随之压平；③ 封面翻到一半时，扉页的底与字浮现（0.38 秒），再过 0.25 秒，上面“命书”与卷名浮现（0.42 秒，着色器里 `uBody`、`uTitle` 两个量，在“只有纸”的底与完整的页之间混合，不重画纹理）；④ 停 0.25 秒；⑤ 翻到第一个对页（弹簧 ω = 12、ζ = 0.9，0.65 秒后即可操作，回弹的尾巴不用等）。演出用挂钟计时（不是每帧 dt）。减少动效、手机、WebGL 不可用时没有这段演出（退回 2D）。
- **合上**（`leaveReading`）：翻到左边的纸一起翻回右边（0.32 秒，一张张错开），再绕书脊合拢（`setLift('shut')`），同时相机退回、书走回原位；封面合上后才收起纸、露出合着时的书页。
- **扉页**（`pages.js` 的 `frontispiece`）：上面是小字“演 算 天 机”，下面一行大一点的“命 书”，然后是卷名大字、全称、所问方向、你写的问题、日期、朱印“命”。

### 峰值演出（克制的高光时刻，2026-10-28）

每一卷一个，只用桌上的东西，不加特效；减少动效时都不播。

- **签落**：签从筒口飞出，在桌上**弹两下**再停稳（3D 里反弹系数 0.5，两下清楚的起落）；第一次着地的落点溅 **3 到 5 个墨点**（`pieces/common.js` 的 `inkDots`：桌面上的贴花，一团主墨加溅出去的小点，落纸后 0.35 秒内洇开约 28%，9 秒里淡去，淡去用 250ms 一步，不占满每一帧）；停稳 **300 毫秒**后，签条（签名）**淡入**（0.6 秒），同时横躺的那一支**淡出**（0.45 秒）——横躺的签与签条只留签条。
- **卦成**：最后一爻落定时，三枚铜钱**轻轻一颤**（各自微微跳起 1.6 毫米、转一点点，0.62 秒内衰减）与一声很轻的铜响，1.1 秒后卦成。
- **出兆**：兆纹一道道裂出来的 2.1 秒里，甲面泛暖（一盏暖色点光，强度随生长进度的平方升到 1800 坎德拉，6 厘米外约 50 勒克斯，昼夜都看得出、不烧白），裂完后 1.1 秒内**慢慢收住**。这盏灯挂在器物上、不挂在会翻转的龟甲上（以前挂在甲上，翻过来灯跑到甲下面，光几乎照不到甲面，所以怎么调都弱）。
- **书摊开**：见上“摊开的演出”。

### 书说话：整本书入画，封面掀起（2026-10-28）

- 书说话时，**封面绕书脊掀到 128°**（过了竖直，向书脊一侧倒靠，像一扇打开的盖子，看得见封面的里子），**整张扉页**露出来，不是立着的一面墙。右装书的书脊在右，封面从左边掀起、向右倒，相机在正前方，所以掀起的封面不会挡住扉页（早先的横放书、书脊在里侧，掀起的封面像一堵墙立在扉页后面）。
- 仪式里书缩到 0.9 倍，退到桌子里侧的左边（`POSES.ritual`：x = −31、z = −19），整本书与掀起的封面都在画面里，扉页上的字不被桌上的器物（签筒、纸笺）挡住；器物的位置由版面决定，书给它们让开。
- 字仍是 DOM（行书，`.voice-plane`），按扉页四个角投影到屏幕（`pageQuad` + `quadMatrix`）。字号 25px，另描 0.4px 的同色细边（龙藏体字面偏小、笔画细，倾斜的页面把竖向压扁约两成）。**不再加随灯光方向的明暗遮罩**（以前背光一侧、夜里字被削到 58%，细笔画读不清）：字是墨，`mix-blend-mode: multiply` 叠在受光的纸上，纸暗字也跟着暗。实测（2880×1800 与 1440×900，昼夜）：写出来的字，最深的 0.3% 像素对纸的对比 12.9–14.8:1（要求 ≥ 4.5:1）。

### 夜里读命书看得清（2026-10-29）

问题：夜里的灯是暖色、又正照在书上，纸被照成一片发黄的白，深色的字乘上很亮的暖光，发橙发褐；页是纹理、缩小到屏幕上之后，思源宋体与霞鹜文楷的细笔画只剩半个像素，更虚；次一级的字用的是 0.5、0.74 的淡墨。

做法（读命书的纸，`three-book.js`、`paint.js`、`Reader.svelte`）：
- **页的墨色比分享图更实**：`paint.js` 里页自己的一份 `C`：正文（soft）`rgba(27,23,18,.95)`、次一级（dim）`.9`；分享图仍用 `poster.js` 的原色。
- **字略加粗**：`paint.js` 的 `embolden(g)`：画每一页时，深色的字（≤ 46px）在 `fillText` 之后按字号描一道同色细边（0.034 倍字号，至少 0.5px）；浅色字（朱印上的白字）、大标题不描。
- **夜里纸的底色与亮度**（`three-book.js` 的 `tint`）：纸材质的颜色乘 `(0.82, 0.96, 1.5) × 0.45`（夜里，昼里为 1）：红绿压一点、蓝抬高，把暖光抵成接近中性的白，再整体压到约 0.45，纸的亮度落在 0.8 上下，与昼里一样。灯下的纸太亮时，深色的字也被照得发亮（字的亮度跟着光走，纸已经烧到顶了），压下来字才黑、对比才高；桌子与四周仍是暗的暖光。以前整体压 0.72、不抵暖光：字发褐、发暗。
- 没有另加读书灯：只改纸的色，已经够了。

实测（headless Chrome + d3d11，`deviceScaleFactor = 2`，即 2880×1800 的截图；每页取页内一块，纸 = 亮度的 80 分位，字 = 最深的 0.3% 像素，WCAG 相对亮度对比）：

| | 纸的亮度 | 左页最深字 / 纸 | 右页最深字 / 纸 |
|---|---|---|---|
| 昼，前 5 个对页 | 0.744 | 11.2 – 14.8 : 1 | 9.6 – 15.0 : 1 |
| 夜，前 5 个对页 | 0.83 – 0.85（左）、0.71 – 0.73（右） | 12.1 – 15.3 : 1 | 10.4 – 15.1 : 1 |

细小的字（页上最淡、最细的一级：账本的小注、隐私说明，约 19px 的霞鹜文楷）单独量：昼 9.7、夜 7.4（以前夜里 1.9）。页脚的注是浅字压深底（`#ece4d0` 对 `#0e0b08`），约 15:1。每次动了页的墨色、字号、夜里的灯，重量一遍。

### 穿模检查（2026-10-29）

`window.__desk.overlaps()`（只在 `?debug` 下，`scene/overlaps.js`）：对场景里每件看得见、有实体的东西（每件器物、木签、筊杯、书的封面 / 书页与底板 / 书脊、翻着的纸与两叠纸）取世界坐标里每个网格的定向包围盒（OBB），逐对做分离轴测试，返回 `{ pairs: [{ a, b, depth, meshes }], below: [{ name, y, mesh }], off: [{ name, over }], count }`：互相穿插（深度 > 0.04 厘米，纸薄，别把压在纸上的东西漏掉）、最低的顶点低于桌面（0.12 厘米以上）、整件越出桌沿。同一件东西自己的零件之间不比；接触影、墨点、烟、拾取用的替身、透明的不比；书脊包封面的边、封面绕书脊转的铰链处（封面厚度让不开，≤ 0.7）、纸与纸（层次由 `curl.js` 排好）是已知的、不算。**每次动了桌上的位置、尺寸、动画，用它在首页、三卷仪式的各个时刻、书说话、摊开、翻页、合上里扫一遍**（脚本不入库：走一局，在每个时刻 `JSON.stringify(window.__desk.overlaps())`）。

### 性能预算

测量方法：Chrome（无头模式，真实 GPU：NVIDIA GTX 1060，ANGLE D3D11，`--use-angle=d3d11 --enable-gpu`），1440×900，页内 `requestAnimationFrame` 的时间戳加 `PerformanceObserver`（`longtask`）；同一套脚本走完一局后读命书，点击翻页 4 次、拖页角翻页 3 次。（有界面的 Chrome 在这台机器上起来十几秒后会被环境终止，所以用无头加真实 GPU；渲染走同一条 GPU 通路。）

| 指标 | 预算 | 实测（卦卷，WebGL，dpr 1） |
|---|---|---|
| 命书翻页的帧间隔 | 1 倍速稳定 60fps（≤ 16.7ms） | 点击翻页：平均 4.3ms，p95 4.3ms，最长 20.8ms，1416 帧里只有 1 帧超过 20ms；拖页角：平均 4.7ms，p95 8.4ms，最长 25ms，1233 帧里 4 帧超过 20ms（页面的 rAF 在无头模式下不受显示器刷新率限制，所以比 16.7ms 小得多） |
| 主线程长任务（> 50ms） | 0 | 0 |
| 翻页时重画的纹理 | 0 | 0（翻页时只改顶点与法线） |
| 静止时 | 一帧不画 | 一帧不画（`engine.busy` 为假时 rAF 停） |
| 保存（分享图）导出 | 页面不卡死，耗时不随起卦次数增长 | 无头软件光栅（最慢的情形）：签 0.55 秒、卦 1.2 秒、卜 0.5 秒；18 次操作的命盘 0.5 秒（以前 4.6 秒以上，且随次数增长）；再点“保存”15ms（同一局只画一次） |
| 页纹理内存 | ≤ 约 80MB | 11–12 页、dpr 1（每页 750×1050）：CPU 画布约 40MB，GPU 纹理同量级（含 mipmap 约多三分之一） |

**不能做的写法：**
- **不要把每帧变化的值写成 CSS 变量，尤其写在有大子树的祖先上**（自定义属性默认继承，一变就让整棵子树重算样式）。
- **不要给整页大小的元素做 `filter` / `backdrop-filter` / `mask` 的动画。**
- **不要用 `getBoundingClientRect` 当页面里的 px**（书在缩放、倾斜过的场景里，量出的是外接矩形）。
- **不要为画命盘一段一笔地描边**：`loom.js` 把相邻 7 段并成一笔、丝的总数封顶 360（以前每次操作 60 束丝 × 420 段，起卦三次就是数十万笔带 `multiply` 混合的描边，导出图片时一次性栅格化，会卡住浏览器）；每画 5000 笔让出一次主线程。
- 声音引擎在空闲时建好（`warmAudio`）：第一次 `new AudioContext()` 在 Windows 上占主线程约 60ms，别落在第一次点按里。

### 保存卡死的根因（记录）

分享图的命盘用 `weave()` 离屏重织一遍：每次操作 60 束丝，每束 420 段，**一段一笔**（`lineWidth`、`strokeStyle` 各不同、`multiply` 混合）。卦卷起一卦至少 6 次操作，"不认再起"最多三卦共 18 次，约 45 万笔描边；这些描边在画的时候只是记进画布的指令列表，**`toBlob` 才一次性栅格化**，在主线程上一口气跑完（无头 Chrome 的软件光栅实测：3 次操作 1.3 秒、6 次 2.4 秒、12 次 3.3 秒、18 次 4.6 秒，随操作数线性增长；有界面的真实 GPU 浏览器没能在本批复现——那台环境里有界面的 Chrome 起来十几秒就被终止——所以“卡死”的程度以用户的报告为准，根因（笔数随起卦次数线性暴涨、导出时一次性栅格化）已由上面的实测证实）。签卷最多 9 次、卜卷最多 3 次，所以最先在卦卷上撞到。改法见上面的"不能做的写法"。

### 静止时

- 静止时：3D 字盘约 18 帧/秒（只有漂移），读命书时暂停；书的话、器物的 rAF 都只在有动静时才跑；命书静止时一帧不画。

### 书的形与装订（右装，2026-10-29）

- **竖长**：宽 26、高 36 厘米，与命书的页（600×840）同样的 5:7。以前桌上合着的书是横放的（书脊朝里、宽大于深），看着像个横本子，而命书的页是竖的；现在封面、纸边、订线、题签都按竖的画，书脊沿竖向。
- **传统右装**：书脊在右，封面从左边（书口）向右绕书脊翻开，翻开后第一页在左；读的时候**从右往左翻页**。实现是**镜像**：`book3d.js` 里整本书（`inner`）`scale.x = -1`，书脊本来在本地 x 的负端，镜像后到了世界的右边；封面（`pivot` 绕书脊转）、纸（`three-book.js`，`curl.js` 一行没动）、点页与拖页角（本地坐标）都因此自然镜像。镜像后要翻回来的只有两处贴图：封面（画布按看到的样子画，`repeat.x = -1`）与命书的纸（`sheetGrid` 的 uv 反走）。**代价很小**：翻页、拖页角、惯性、背面透字、阴影都不用改（three.js 对负缩放自动翻转三角形的朝向）。
- **页的订口、页码跟着换边**：右装时每张纸的正面（偶数页）落在左边、背面（奇数页）落在右边，`Reader.svelte` 的 `sideOf()` 给 `ground()`（订口的暗处）与 `folio()`（页码在外侧下角）换边；左装（2D）与右装的页纹理签名不同，`rtl` 变了会重画。
- **方向键**：右装时 ← 往后翻、→ 往前翻（手里的动作是把左边那一叠翻到右边）；2D 左装不变。屏幕阅读器的朗读顺序：每个对页先读右页（第 2k-1 页）再读左页（第 2k 页），与眼睛的顺序一致；扉页（单独的第 1 页）先读。
- **题签**：封面左上竖贴一张窄纸，竖题“演算天机”（古书的惯例，右装书的题签在封面左上）；残印位是题签下面一列四个（签、卦、卜、星）。订线四眼在右边的书脊上。
- **2D 退回**（手机、减少动效、WebGL 不可用）：合着的书与读命书的 DOM 页**仍是左装**，没有镜像——那一套是 CSS 3D / 平铺的两页，镜像要把 `book.css` 里的转轴、纸边、题签、页序再翻一遍，收益只是 2D 退回里的一致；以后若要统一，改 `book.css` 与 `Reader.svelte` 的 `show2d` / `go` 即可。

## 20. 无障碍、按钮层级与术语注（2026-10-25）

### 页脚与按钮槽

- **页脚只有两行**：第一行是这一步的说明（读命书时是这一页的脚注）；第二行左边是存疑，中间是本卷的步骤，读命书时右边是合上、再来、请大师细说、保存。源流、关于只在天头栏，页脚不重复（首页与讲解页没有天头栏的那两个链接，仍在页脚第二行）。
- **主按钮不在页脚**：仪式里"往前走"的那个动作（问、卜、定、掷筊请示、解、观象……）放在**桌面下方的中央**，紧挨着器物，一个按钮槽组件（`core/desk/BenchSlot.svelte`）。屏用 `<Spread {act}>` 把它交给 Codex；读命书时没有槽，按钮在页脚（`foot`）。三维器物与桌布光改动后（器物位置会变），槽的位置只需调 `styles/foot.css` 的 `.bench-slot`；桌上为槽留的空是 `.desk-items` 的 `padding-bottom`。
- **按钮的分量**：
  1. 朱印、`.btn-primary`（朱）：只给"往前走"的唯一一个动作；一屏最多一个朱。
  2. `.btn-pair`：**二选一**。两个按钮同样大小（`min-width: 12em`、48px 高）、同样样式（米白细框、深底），**都不朱**，哪一个都不比另一个更"该按"。掷筊（依规矩，重求一签 / 我偏要这支，或 受签 / 不认这支签，重求）、解卦（受卦 / 不认，再起一卦）、读兆凶时（王占曰：吉 / 王占曰：从兆）、对贞（算了 / 去灼）、验辞的三个回答，都是 `.btn-pair`。
  3. `.btn-ghost`：旁路，下划线文字（再灼一处、对贞：反过来问）。
  4. **存疑**：小小的墨框（`.doubt-btn`），米白字、半透明细框，**悬停或聚焦时才点朱**；字号 13px，比主按钮小一圈；不再是朱印，不再呼吸。
- **图例收进纸笺**：掷筊的规矩、一爻怎么算，不再散落在木头上，收进一张带标题的纸笺（`.legend-plaque`，`<details>`）：桌面展开，手机默认合着、点标题展开。字号 17px 起，桌面场景缩到 0.8 倍上下之后落在 13–14px；手机上 14px。

### 键盘与读屏

- **书的话**：扉页上的字是逐字洇开的、放在 `aria-hidden` 里读屏读不到。书每说一句，`gloss.js` 的 `onSay` 把原文写进 `stage.said`，`Book.svelte` 里一个视觉隐藏的 `role="status" aria-live="polite"` 区域（在 `aria-hidden` 之外）读出"书说：……"。
- **命书**：正文只画在 Canvas 上，所以 `Reader.svelte` 另渲染一份视觉隐藏的平行文本：每页一个 `<article>`，标题 `<h2>` 来自页描述的 `title`（`book/pages.js`），正文是页的 `text`。每次翻页，朗读区写出"第 N 个对页，共 M 个。左页标题。正文。右页标题。正文。"，**N 从 1 数起**（手机单页是"第 N 页，共 M 页"）。画布模式下另备两个平时看不见、聚焦才显出来的"上一个对页 / 下一个对页"按钮。命书的容器是 `role="region"`，翻开后拿到焦点；书没摊开时 `inert`。
- **焦点**：从首页进卷后，焦点落在桌上第一个能操作的东西（择域是第一支木牌，摇签是签筒，入口屏是"问"印）；换屏后若焦点丢了（原来那个按钮没了），同样落回去。命书翻开，焦点到命书；离开命书、回书桌，焦点放回刚才那一卷的器物。页面有一个视觉隐藏的 `<h1>`（卷名）。桌上暂时用不到的东西（首页的器物、非仪式阶段的桌面）用 `inert`，不用 `aria-hidden`：既读屏不可见，又 Tab 不进去，也不会留下“焦点在被隐藏的元素里”。
- **按住才能操作的器物**（签筒、龟壳、钻凿）：页脚说明里写明键盘的替代：Tab 聚焦，按住空格（或回车）。
- 焦点环：输入框聚焦是 2px 墨色外框（对纸 ≥ 10:1），不是 1px 底线；全站 `:focus-visible` 仍是 2px 外框。

### 触控目标与对比度（375 宽）

- 主题印、声、书桌 / 卷首、通灵开关、存疑：视觉大小不变，用透明的伪元素把点击区撑到 ≥ 44×44；页脚链接、主按钮、图例标题本身 ≥ 44。术语是正文里的行内链接（WCAG 2.5.8 的行内例外），点击区也向外撑了一点。
- 占位符 ≥ 4.5:1（浅 5.6 / 深 4.7）；手机"未开卷"提到纸白（原来深字压在深桌上，1.1:1）；页脚步骤的点与箭头 7:1；桌上的朱字（阴杯）在深木上用亮朱 `#ef6b5d`（4.5:1 以上）。

### 术语纸条注

- 术语用 `<Zhu term="…">` 加点线（`core/Zhu.svelte`），点一下（或 Tab 聚焦后按 Enter）在术语旁贴出一张带胶带的纸条（`ZhuPanel.svelte`，样式 `styles/zhu.css`）：术语名、出处标签（出自古籍 / 民俗 / 考古 / 本作原创）、正文、依据。点别处、按 Esc、换屏、缩放窗口都会收起；Esc 后焦点回到术语。桌面与手机同一种方式。

### 灯下实物的性能（2026-10-25）

- 沿用上面的预算：**静止时 0 帧**（实测首页静置 3 秒 0 帧）；页面不可见时不渲染；dpr ≤ 1.5；纹理在创建时画一次，不在每帧重画（只有龟甲的兆在生长的 2 秒里每帧重画一张 600×840 的纹理）。
- 渲染按需：`invalidate()` 请求一帧；动画靠 `addTicker`，没有动画就停；物理在自己的 rAF 里推进，只有画面变了才画（`view.draw` 里比对签名）。
- 阴影贴图在每次渲染前更新（静止时不渲染，所以也不更新）。首帧要编译着色器、生成木纹，约 1 秒；之后每帧 CPU 约 0.5–1 毫秒。
- three.js 与整个 3D 书桌是动态 import 的独立一块，不进首屏。
