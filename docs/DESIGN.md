# 设计规范：宣纸朱批 × 摇动控制

> 所有美术改动以本文为约束，改完逐项过 §9 的检查清单。
> 早先的方向"立轴 × 绀纸金泥"（深蓝纸、泥金字）已弃用：泥金在手机上难读，而朱批的"审阅"关系与作品立意直接对应。

## 一句话

整个作品是一页**古籍**：宣纸为底，墨写正文，枯笔墨痕做骨架；大师对你的评语用**淡墨写在天头，作眉批**，朱笔只用来圈点（句尾的"〇"、关键数字、警示句的着重点），像皇帝批奏折时的圈点。器物用**水墨写意**来画，但按**真实物理**来动。桌面上是一张摊开的书页：天头眉批、中间仪式、右侧一栏"注"（见 §12）。

## 1. 为什么是眉批与圈点

旁批是作品核心：大师一边看你求签，一边给你下判断。眉批写在天头，是上位者审阅、批示的位置；朱笔的圈点落在它身上——被观察、被评判的关系直接画进了视觉里。

（早先眉批整句用朱色，后改为淡墨：满篇的红字抢了正文，也让"朱色"不再稀有。现在朱色只落在最该被看见的点上。）

## 2. 纸面

| 元素 | 做法 |
|---|---|
| 宣纸 | 暖白 `#efe6d0`，叠纤维纹与低频的深浅斑驳；内容上方再盖一层极淡的纸纹，墨字与朱印也带纤维，像印在纸上。**不用 `mix-blend-mode` 混合整层内容**（Chrome 下出现色带，老旧内置浏览器风险更大）。噪声图案的频率 × 尺寸须为整数，平铺才无缝 |
| 版框 | 古籍的"四周双边"：外粗内细两道墨线框住画面 |
| 朱丝栏 | 竖向朱红细线，间距 44px，不透明度约 0.24；木版印刷的质感：线条轻微抖动、偶有断口，一块图案里三根线断口错开 |
| 眉批区 | 页面顶部一条横带；大师的批语写在这里（见 §4） |
| 角按钮 | 左上"卷首"（仪式页的入口屏上写作"目录"），声音开关"声"在仪式舞台的右上角（桌面上在注栏左侧）；都在版框之内 |
| 案 | 桌面上纸的外侧是"案"（`.an`），案上铺着深墨色的字盘（`#an-board`，见 §13）；手机上纸几乎占满全屏，天头、地脚各让出 22px 给字盘 |
| 枯笔墨痕 | 每屏至多一笔大墨痕做构图骨架（SVG 路径 + 位移与条纹滤镜模拟飞白），标题可反白压在墨上 |
| 墨点 | 少量溅墨点缀，不超过 5 处 |

浅色下不用金色，不用满屏红金。

## 4. 字

| 用途 | 字体 |
|---|---|
| 大标题（演算天机、屏名） | 志莽行书 Zhi Mang Xing（枯笔行书，气势） |
| 签名、结局名、印文 | 马善政楷书 Ma Shan Zheng |
| 眉批（旁批） | 马善政楷书，**淡墨（墨 72%）**，手机 16–17px、桌面 20px；朱色只给句尾"〇"、关键数字（自动识别文中的数字与百分号）、警示句的着重点。**不用草书**：草书（如刘建毛草）在手机上认不清 |
| 注（注疏） | 思源宋体，墨色；术语名用 600 字重（见 §12） |
| 正文、按钮、表单、账本 | 思源宋体 Noto Serif SC |

**按钮、表单、导航、账本不用书法字体**，保证可读。手机端正文不小于 16px，说明文字不小于 14px。

眉批：天头是一个**固定大小的槽**（两行高），**同一时间只显示最新一条**，不叠放历史。理由：早先的做法是逐字往 DOM 里追加，每多一个字就重新折行、重排，高度会跳；叠放"新条两行 + 上一条一行"就是三行；为了容纳它们，顶部还要预留近 100px，把各屏挤出滚动条。现在的做法：

- **文字先整句排好版，再逐字洇开**：每个字一开始就在 DOM 里，只是被动画延迟压着没出现，所以写字的过程中版面纹丝不动。
- **折行落在句读上**：按标点切成语段，每段是不可拆的一块，放不下时整段移到下一行（"你问尘缘，想了 3.9 秒。／你在意别人"），不在词或"3.9 秒"中间断开；不用省略号截断。
- 槽里一行或两行都垂直居中，换条时不跳；换条时旧的原地淡出、新的接着写，不叠放。
- **同一类批语只留最新一条**（如连点"功名、尘缘"时，新的顶替旧的，不排队）；后面排着队时写得更快、停得更短。
- 句尾圈"〇"（朱）在版面里先占好位置（不显示），写完才显出来，免得最后一刻把末段挤到下一行；关键数字用朱；警示句的着重点用朱。
- **批语不加底框**（矩形底与宣纸、墨痕格格不入，且 `backdrop-filter` 做不到只模糊字形），改为字的四周一圈纸色柔光（多层 `text-shadow`）；毛玻璃只留给角按钮；回卷首时清空。

## 5. 器物：写意的画，真实的动

- 签筒、竹签画成**水墨**：淡墨晕染的筒身、粗细不匀的墨线、竹签是一笔笔墨痕；筒身只盖一方朱印。
- **印**：外缘不规则、内框线断续、朱面剥蚀（越靠边越密、中心近乎完整），像石头刻的、蘸印泥盖的。网页上的 `.seal` 用一道静态的 SVG 位移滤镜起毛边（只在绘制时算一次）加纸色噪点蒙版；摇签筒上的印在转动的组里，不能用滤镜，改用静态的不规则路径加碎点；分享图里的印用 Canvas 按种子画出同样的做法。
- 筊杯保留红漆实物色，用墨线勾边，像工笔着色。
- 落地溅起的是**墨点**，不是金粉。
- 物理与输入见 §6。

## 6. 摇动控制

- 手机加速度计为主输入：倾斜决定器物倾角，晃动力度累积成"能量"；iOS 在第一次点击时请求权限。
- 回落：按住器物左右拖动；按住不动时器物自己轻摇；键盘按住空格。
- 器物本身就是控件，文字按钮只作回落与无障碍入口。
- 按能量出结果，不按计时。
- 每次碰撞同时有画面、声音、震动（安卓）。

物理参数：重力 2400 px/s²，倾角弹簧 k 90 / 阻尼 12，落地恢复系数 0.35，摩擦 0.8，固定步长 1/120 秒。一次摇签 2–4 秒；签落地到签诗出现不超过 1 秒。"减少动效"时跳过飞行与弹跳。

## 7. 避免

（部分借鉴 InkView 的设计原则，MIT：https://github.com/qybaihe/inkview ；未采用其 PNG 素材，因本项目不引入位图）

- 宫廷红金、仙侠游戏界面、影楼古风；
- 发黄做旧的脏纸、压在小字下的纹理；
- 给每个元素都描一圈边框——墨线用来分隔，不用来包框；
- 书法字体用在按钮、表单、账本上。

## 8. 墨与水：会动的纸（2026-09-30）

纸面静止时什么都不多画；只有指尖点按、换屏、落签这些时刻，才有墨或水出现，随后淡去。实现在 `src/core/ink.js`（一层盖在画心上的画布，夹在内容与纸纹之间，所以墨与水也带着纸的纤维）。

| 时刻 | 效果 | 说明 |
|---|---|---|
| 签卷入口载入 | 墨痕被一笔"写"出来，标题随后在墨里洇出 | 墨痕是静态图 `public/img/title-ink.svg`（光栅化一次），"写"是平移一张预先带飞白毛边的蒙版，每帧不重算滤镜（手机上像素多，逐帧重算会卡） |
| 签卷入口静候 | 墨痕边缘每隔一两秒洇出一团极淡的墨晕，慢慢扩大、淡去；偶尔下缘鼓起一颗墨珠，坠下，落在纸上洇成一小团、荡开两圈水纹 | 只在签卷入口屏、页面可见时（卷首目录页是静态的，不放墨痕）；**不画线**（卷须像蜘蛛腿，拖出的流痕像蛛丝，都已去掉） |
| 任何点按 | 一小团柔边淡墨晕 + 两圈水纹 | 红色按钮与签筒上不落（按钮自己有按下的反馈，签筒上手指一直在动） |
| 换屏 | 新的一屏从按下的地方洇开，边缘是湿润的软边，底下一团极淡的墨晕和一圈扩散的水纹 | CSS `@property --r` + 径向蒙版；不支持的浏览器退回原来的淡入 |
| 眉批 | 每个字由糊变实，笔尖是一点朱 | 取代原来的 ▍ 光标 |
| 落签 | 签名像盖印一样落下（带回弹），落点洇开一团墨晕、起一圈水纹；签诗逐字洇开 | 摇签时落地的墨点落纸后会再洇开一圈 |
| 掷筊落地 | 两块筊落点各洇开一小团墨晕和水纹 | |
| 结局 | 印章在进入视野时盖下，洇开一团朱晕和一圈水纹；判词、"不过……"逐字洇开 | 用 IntersectionObserver，滚到才播 |
| 通灵等待 | 一滴墨落进纸里，化开，隔几秒再一滴，伴一声水滴 | 取代三个闪动的圆点 |

约束：

- **质感取"水洇在宣纸上"**：边缘柔和的淡墨晕，加细而淡的水纹。**不画放射的细线（像蜘蛛腿），不画吊着的细线（像蛛丝）**——早先试过的墨晕卷须与流墨，就因为像蜘蛛而去掉了。

- 画布只在有动静时才跑 rAF，静止时零开销；运动中的东西不用 SVG 滤镜，靠柔边的径向渐变叠层。
- 朱色规则不变：只有印与朱批带朱，所以朱色的晕与纹只出现在按印、落印时；墨与水一律用墨色。
- "减少动效"下：画布层整体关闭（`createInk` 返回空实现），换屏不做洇开，通灵等待退回三个点，其余 CSS 动画被全局规则压成瞬间。
- 调试：页面加 `?debug` 后有 `window.__fx`，`__fx.advance(dt)` 可手动推进一帧（面板隐藏时 rAF 会暂停）。

## 9. 每屏完成前的检查

1. 底是宣纸，有版框和朱丝栏；
2. 每屏至多一笔大墨痕；
3. 朱只用于印章、朱批圈点（〇、关键数字、着重点）、阴杯、最终判词与关键操作按钮；眉批、账本旁注、"实话"与注的正文是墨；
4. 正文与按钮用宋体，对比度足够；
5. 器物是水墨画法，能摇、能按住、能用键盘；
6. 在"减少动效"下仍能完成流程；
7. 桌面 1440×900、1366×768 与手机竖屏 375px 宽下都完整可见；
8. 新增的动效符合 §8：静止时不多画、朱色只给印与朱批圈点、减少动效下可跳过；
9. 字盘、透字、开卷符合 §13：只用 transform / opacity（开卷用 clip-path，一次性）、静止零开销、页面隐藏时暂停、字盘本身是墨色；
10. **两套主题各看一遍**（角上的"昼/夜"印，或在系统里切换配色）：对比度、朱色规则、金色只在深色里出现、Canvas 与 SVG 画的东西是否跟着换色；分享图仍是浅色宣纸；
11. 3D 场景符合 §18：页面不可见时不渲染、静止与悬停暂停时不逐帧画、dpr ≤ 1.5；手机宽度、`pointer: coarse`、减少动效、WebGL 不可用时退回 2D 字盘。

## 10. 命盘与分享图（2026-10-02）

- **命盘丝线**：每根丝带"笔压"，沿途粗细、浓淡随笔压起伏，最轻处偶有飞白断口；收笔处（右端）渐细渐淡。线头用平头（圆头相邻叠加会叠出一串小珠）。每一束丝下垫一片淡墨，被弃掉的那一掷更淡；阴杯的右半，淡淡带朱。
- **分享图**：下半截衬一幅算法生成的淡墨远山（三层山脊由远及近渐浓，层间一抹云气，脊线是断续枯笔，山腰几笔短皴），只画在内框之内，命盘与二维码压在山前。山脊由一维值噪声叠三个八度生成，种子与这一局相同，所以每个人的山都不一样。网页上不加山：每屏至多一笔大墨痕。
- 参考过但没采用的开源库：rough.js（铅笔白板的涂鸦感，不是木版）、shan-shui-inf（只借思路，远山自己用噪声画）、WebGL 流体模拟（手机耗电、内置浏览器兼容风险，而且这里的媒介是纸不是水）。

## 11. 矮窗口适配（2026-10-02，2026-10-22 随桌面版式更新）

- 桌面以 1440×900 与 1366×768 为主设计：纸宽 `min(1120px, 100vw - clamp(48px, 12vw, 220px))`（1440 宽两侧各露 160px 字盘，1366 宽各 123px），高为窗口高减 20px。眉批槽高度（`--mei-h`）桌面 84px、手机 72–74px（一个两行槽；曾因叠放两条而加到 94–102px，是挤出滚动条的原因）。
- 矮窗口（高 ≤ 780px / 700px / 640px 三档）仍要收紧：间距、入口屏墨痕高度、屏名字号、掷筊板、杯位卡、图例、签卡。桌面的两栏版式（签卡左右分、掷筊"规矩 | 掷"、结局两栏）本身就比单列省高度，1366×768 下三屏都不出滚动条（结局页本来就长，滚动是预期）。
- 内容仍超出一屏时，主要按钮（定、掷筊请示、掷筊/受签/重求）用 `position: sticky` 固定在底部，不必往下滑才点得到。
- **固定的按钮不铺底色**：纸有纹理和朱丝栏，平涂的纸色底会在按钮两侧显出一块发白的长条。实心按钮自己就看得清，描边按钮只加字周围的纸色柔光。
- 手机 375×812 能完整玩一局；注栏折叠，术语点开显示浮注。
- 样式分层：`src/core/styles/`（base 纸与印与按钮、layout 案纸与注栏、paper 字盘与透字与开卷、gloss 眉批、end 结局页、pages 静态页、toc 卷首目录）与 `src/juan/qian/`（qian.css 签卷各屏、fit.css 各档窗口的适配）。

## 12. 桌面版式与注疏（2026-10-22）

桌面是一张摊开的书页，三块：

| 区域 | 内容 |
|---|---|
| 天头 | 大师的眉批（§4），在舞台上方居中，与中间的仪式对齐 |
| 中间 | 仪式：各屏的器物、签卡、掷筊、结局。结局页分两栏 |
| 右侧注栏 | 宽 308px，与舞台之间一道"双线"（`3px double`）；标题"注" |

注疏：

- 仪式里出现术语（掷筊、圣杯、笑杯、阴杯、三杯定签、六十甲子、纳音、签头、时辰、五行、筊杯）时，术语用 `<Zhu term="…">` 标出，**下加点线**（2px 点线，墨 45%）。
- 术语进入视野（IntersectionObserver，阈值 0.6）时，注栏同步添一条注，最新的在最上，较早的淡到 66%；同时出现几个时一条一条错开 0.4 秒。点术语把这一条提到最前并框一下，以便回看。
- 注是讲解，说传统：用思源宋体、墨色，**不用朱**；每条注有术语名、出处标签（出自古籍 / 出自民俗 / 本作原创，小方框，墨色）、正文与一行出处说明。注与眉批分开：眉批是大师在说你，注是在说传统。
- 注的数据集中在各卷自己的 `zhu.json`（签卷：`src/juan/qian/zhu.json`）；每条注要有依据，不确定的写成"各庙说法不一"，不编造典故；原创的设定要标"本作原创"。
- 手机（宽 < 960px）：注栏折叠；点术语，在术语下方（放不下则上方）弹出一张浮注，点别处或按 Esc 收起。
- 每卷另有"源流"页（Markdown，`src/pages/<id>/yuanliu.md`，用 `core/Doc.astro` 排版），讲这种算法的历史、规矩与文献，并注明哪些是古籍、哪些是民俗、哪些是本作原创。

卷首目录（`/`）：古籍目录页。竖排，自右向左，每卷一列：卷名（马善政）、全称、点线、页码，旁边一句简介；开了卷的那一卷盖一枚"入"字朱印，未开卷的墨色更淡、不可进入、标"未开卷"。

## 13. 案上字盘、纸背透字、开卷与盖印（2026-10-22）

### 案上字盘

画心之外的"案"是一盘**反刻的阳文活字**：深墨底（`#2b2620` 到 `#14120f` 的径向渐变，盘边再收暗），每个字是一枚浮雕般的铅字，字身镜像，亮边在左上、暗边在右下，字色只比底亮一点点（低对比，不抢画心）。桌面上它从纸的两侧露出来；手机上只在天头、地脚各露 22px 一窄条。

| 项 | 做法 |
|---|---|
| 实现 | `src/core/paper/board.js`：按案的尺寸把一盘字**一次性**画在离屏画布上（桌面格 38px，手机 22px；整盘镜像，行内次序也是自右向左；约 5% 的位置是空铅），上下两幅相同，再用 CSS `transform: translate3d` 循环滚动一个 `tileH`（约 9px/秒）。滚动时不重绘、不跑 rAF；窗口尺寸变化后（防抖 250ms）重画一次。画布最多 dpr 1.5，纹理总量压在约 9M 像素以内 |
| 字 | 一律用思源宋体（活字感），只取 BMP 里的汉字，扩展 B 区以后的字一律不用，免得没有字形时回落到系统字体、显示成方框。部首表里思源宋体没有字形的字已经事先剔出（`shuowen-bushou.js`） |
| 按卷取字 | 路径第一段是卷 id 时，取该卷模块的可选字段 `zipan`（字符串，或返回字符串的函数，可异步，见 `src/juan/index.js`）；没有 `zipan` 的卷、卷首目录页与静态页，用《说文解字》540 部首（`src/core/paper/shuowen-bushou.js`，公有领域）。各卷用什么：签＝六十一首签诗，卦＝《周易》经文，卜＝甲骨卜辞释文，字＝《说文》，历＝历书宜忌用语；目录＝《说文》部首 |
| 悬停与按住 | 鼠标悬停在字盘上，整盘暂停，移开恢复（`:hover`，仅 `hover: hover` 设备）；触屏按住暂停，松手恢复；页面隐藏时暂停（`visibilitychange`） |
| 点一个字 | 那里"拓"出一枚**小朱印**（朱色，阴文，字是拓回来的正字），随那枚铅字一起滚；同时洇开一团墨（`ink.js` 的 `wash`，在深底上用比底更黑的墨，水纹是一圈淡淡的亮痕）。朱印停 5 秒后淡去，最多留 8 枚。朱印另放一层、盖在墨晕之上，与字盘同一段动画，所以暂停与滚动始终同步 |
| 减少动效 | 字盘静止；点击仍落朱印，只是没有动画，也没有墨晕（`createInk` 返回空实现） |
| 约束 | 字盘本身是墨色，不用朱；只用 transform 与 opacity；静止时零开销（实测静止 3 秒内页面脚本的 rAF 调用为 0，墨晕散尽后也为 0） |

### 纸背透字

画心里的**镜像大字**，像背面的字洇透过来。只在卷首目录页用（`Paper.astro` 的 `tou` 参数，一个字符串，取前三个字；图谱页以后接，传同一个参数即可）。

- 不透明度 4–6%，字号 120–380px，各自按 140 / 170 / 200 秒来回漂 26–34px（`transform`，`alternate`），压在正文之下；手机上只留两个字。
- 字用思源宋体，墨色。页面隐藏时暂停，减少动效下静止。
- 它不是"每屏至多一笔大墨痕"的那一笔：墨痕是构图骨架，透字是纸本身的底色，更淡、更慢，不参与构图。

### 卷首开卷

进入目录页的**本次会话第一次**（`sessionStorage` 的 `stj-kaijuan`），纸像卷轴一样展开：画心用 `clip-path: inset(0 50% 0 50%)` 揭开到全幅，两根卷轴（墨褐木轴，不用金）从中缝滚到两边，最后淡去。1.15 秒，缓出缓入。决定放在 `<head>` 的内联脚本里，在首帧之前加上 `html.kaijuan`，免得先闪出整页。减少动效下跳过，也不记标记以外的任何状态。

### 印章按下

所有朱印按钮（`Seal.svelte`）共用：

1. **按下**（`:active`）：印往下压，`translateY(2px) scale(.9)`，略暗，60ms。
2. **松手**（`click`，键盘激活同样）：`.is-print` 播 0.42 秒的一震（回弹到 1.05，再左右各偏 1px，落定），同时印边晕开一圈朱色（`box-shadow`，最远 `--s × 0.13`，淡去）。
3. 多数印按下就换屏、按钮随屏消失，一震还没演完：这时在原处留一枚**影印**（克隆的印，不接事件）把这一震演完再移除。
4. 毛边滤镜 `#seal-rough` 的区域放宽到 ±14%，印迹那一圈才不会被截掉。
5. 减少动效下全部跳过。

## 14. 卦卷的器物与卦画（2026-10-22）

- **龟壳与铜钱**（`src/juan/gua/shell.js`）：与签筒同一套做法（§5、§6）。龟壳是淡墨晕染的壳身，壳上几笔盾片的接缝，一方朱印；铜钱用旧铜的低饱和色（灰褐，不用金色），墨线勾边，字面是“天机通宝”四字，背面光素，只有星与月。运动中的器物不用 SVG 滤镜。
- **真实的动**：重力 2400 px/s²，落地恢复系数 0.35，固定步长 1/120 秒；钱从壳口飞出，飞行时转过整数个半圈，落地后在原地摇摆衰减，像一枚旋转的硬币慢慢停下，所以看到的朝向与记下的一致。接口与签筒相同，沿用公共的摇动控制（拖动、按住、晃手机、空格或回车）。
- **卦画**（`Hexagram.svelte`）：一爻一笔墨，沿路径一笔写成，不用滤镜；阳爻整条，阴爻中间断开；变爻旁点一圈朱（老阳〇、老阴×），属朱批圈点。
- **命盘的织法**：一爻一束丝；少阳平直，少阴在中间分开，老阳胀成一个圈，老阴在中间交叉；变爻的中段带一点朱。

## 15. 卜卷：龟甲、炭火、烟与兆纹

- **器物**：龟腹甲用淡墨与骨色（低饱和的土黄）画成，背面粗糙、正面略光；不引入位图，不用金色。炭火与刚裂开的裂缝尖端用低饱和的**赭红**（`rgb(168,84,52)`），不与朱色混淆；朱色仍只给印、判词和关键按钮（以及改判那一束丝上的朱笔）。
- **烟**：Canvas 粒子，有浮力、受气流、越升越散、渐隐；只在有火或有烟时才跑 rAF。
- **兆纹**：`src/juan/bu/crack.js` 按种子生成（纯函数，同一个种子同一道兆），页面、命盘旁的兆图、分享图共用同一份数据与同一个绘制函数。生长动画在“卜”的一刻播出；“减少动效”下直接长全。
- **兆象映射**：集中在 `src/juan/bu/omen.js`，是本作自己的设定，**不得写成史实**（商人如何据兆定吉凶并无定论）。
- **刻辞**：楷书，竖排，加刀刻的痕（SVG 位移滤镜 + 上沿浅色、下沿深色的两层）；版面由 `carveLayout` 统一，页面与分享图一致。没有可用的开源甲骨文字体，所以只在装饰处（入口、源流页）用本卷手绘的少量仿甲骨字形（`glyphs.js`），旁边注明“本作仿甲骨字形手绘”。
- 命盘：每一灼一束丝，丝形随兆象变；改判的那一束在中缝断开、由朱接上。

## 17. 双主题：宣纸与乌金拓

| | 宣纸（浅色，默认之一） | 乌金拓（深色） |
|---|---|---|
| 意象 | 宣纸、墨、朱批 | 碑拓：墨底，纸白字，斑驳，泥金点缀 |
| 纸面 | 暖白宣纸，纤维与深浅斑驳，朱丝栏 | 墨底：亮丝纤维、拓片的白斑、低频的深浅；朱丝栏退到极淡；盖在字上的一层细碎磨损 |
| 字色 | 墨 | 纸白（`--ink`），题名、版框用泥金（`--leaf`） |
| 墨晕 | 淡墨 | 淡金偏白的一团光（`ink.js` 的 `inkRgb()`） |

- **机制**：`<html data-theme="light|dark">`。`Paper.astro` 的 `<head>` 里有一段内联脚本，**在首帧之前**设好它：先读 `localStorage['stj-theme']`，没有就跟随 `prefers-color-scheme`，读写都包 try/catch。之后系统配色变了，若玩家没手动选过，会跟着变。统计等代码读这个属性。
- **开关**：角上与"声"并列的一枚小朱印（印章式），写当前的主题——"昼"或"夜"，点一下换成另一个。手机上叠在声牌下面。`aria-label` 写明点了会换成什么。逻辑在 `src/core/theme.js`（`setTheme`、`onTheme`、`inkRgb`）。
- **颜色全走变量**（§3）。SVG 里的器物（签筒、龟壳）用 `fill="var(--obj-ink)"` 这类写法，主题一换立刻跟着变，不必重建。
- **Canvas 跟着换**：墨与水（`ink.js`）、命盘（`loom.js`：深色是墨底上的淡金丝，滤色叠加）、2D 字盘（`board.js`，换主题时重画）；换主题时命盘按新配色重织。卦画是 SVG 变量；签卡、角牌是 CSS。龟甲是骨色的实物，两套主题下保持不变。
- **分享图保持浅色宣纸**：它是要带走的一张纸。`weave` 指定 `width`（离屏重织）时一律用浅色。
- **厚度**（CSS，克制，文字始终正面朝向）：签卡是有纸边与纸影的一张纸，悬停时随鼠标透视倾斜 ≤ 4°（`core/tilt.js`，仅鼠标，减少动效下不做）；朱印按钮有"印身"（下缘一道深朱）与软影，按下时下沉 3px、印身压平，松手的一震不变；角按钮是小木牌（木纹、亮边、暗边、下缘一线厚度）。签筒、龟壳、龟甲只补光影，不改交互和物理。

## 18. 3D 场景层

three.js 只用于场景层，文字、按钮、印章仍是 DOM。three 是 npm 依赖，**只在真正要用时动态 `import()`**（`board.js` 里），包是独立的一块，不进首屏。

### 3D 铅字字盘（取代 2D 字盘）

- `src/core/scene/board3d.js`：**一个 InstancedMesh**（一份盒子几何，几千个实例），每个字是一块有厚度的金属活字。字形图集（`atlas.js`）在运行时用 Canvas 画出反字，R 通道即高度；字面的凸起在着色器里对高度图取差分得到法线，边缘倒角在着色器里弯折法线，顶面受光、倒角出高光。不为每个字单独建几何体，不用位图素材。
- 字来自每卷的 `zipan`（同 §13）；约 5% 空铅；深色下约 4.5% 的字泛泥金。
- **交互**：鼠标移过，附近 3.4 格内的活字按距离抬起（每块略有差别，参考木盒里被抬高的活字）；点一下，那一块按下去，原地"拓"出朱印（阴文正字，在着色器里把图集沿 x 翻回来），并洇开一团墨晕（`ink.js`，画在其上的 2D 画布）；朱印停 5 秒后淡去，最多 8 枚；朱印、抬起量跟着那块活字一起滚。
- **滚动**：整盘约 0.24 格/秒向上滚（与 2D 约 9px/s 相当）；悬停（或按住）暂停；整盘只上移一格时才重写数据。
- 浅色：旧木盒里的铅字（灰褐金属，暖光）；深色：墨底，铅字泛冷光，偶见泥金。
- **深色下的写经绢帛**（`silk.js`）：三幅墨底泥金的绢，字取本卷 zipan，运行时用 Canvas 写成泥金字的纹理（一幅另有一枝泥金竹叶）；顶点着色器让它带弧度、缓缓起伏，法线随之变化，字随起伏受光闪动；三幅错开 z 与角度，层层叠叠，远处更暗（景深）。位于字盘之上、画心之后；画心在深色下是半透的墨底（`.has-silk`，不透明度 .88），绢隐约透过来。只在深色主题出现。

### 性能约束

- 页面不可见（`visibilitychange`）时停止渲染，并取消计时器。
- 渲染节奏：有抬起、按下动画时跟随 rAF（落定后立刻停）；只有漂移（滚动、绢的起伏）时约 18 帧/秒（`setTimeout` 50ms 再 rAF）；只剩朱印淡出时约 30 帧；**悬停暂停且没有动画时一帧不画**。
- dpr 上限 1.5。图集最多 1024 字（1536² 画布）。尺寸变化后只在需要更多格子时重建网格。
- 只重写动过的块的实例属性；整盘上移一格时才整体重写。
- 调试：`?debug` 后有 `window.__scene`（`stats()`、`step(dt)`、`hover(x,y)`、`click(x,y)`）。

### 退回 2D

以下任何一条成立，一律用 `board.js` 里的 2D 字盘（§13，功能等价；深色下按新配色画）：

1. 手机宽度（视口 < 960px）；
2. `pointer: coarse`；
3. `prefers-reduced-motion`；
4. WebGL 不可用，或three.js 加载、初始化失败、上下文丢失。

条件在运行中变化（窗口跨过 960px、系统设置变了）时会自动换过去（防抖 200ms）。`?scene=2d` 可强制 2D。
